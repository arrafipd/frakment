## Usage

~~~tsx title="accordion.tsx"
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
~~~

~~~tsx title="accordion.tsx"
<Accordion collapsible defaultValue="shipping" type="single">
  <AccordionItem value="shipping">
    <AccordionTrigger>What are your shipping options?</AccordionTrigger>
    <AccordionContent>
      Standard, express, and overnight options available.
    </AccordionContent>
  </AccordionItem>
</Accordion>
~~~

## Animation

Accordion accepts an `animation` prop on the root, inherited by every content item. Pass a per-item override on `AccordionContent` to diverge from the root setting.

```tsx
<Accordion animation="spring(300, 25)" collapsible type="single">
  <AccordionItem value="a">
    <AccordionTrigger>Question</AccordionTrigger>
    <AccordionContent animation="easeInOut 200ms">Answer</AccordionContent>
  </AccordionItem>
</Accordion>
```

| Form | Example |
| :-- | :-- |
| Named easing | `"easeInOut"`, `"easeOutExpo"`, `"easeSmoothOut"` |
| Named easing + duration | `"easeInOut 300ms"`, `"easeOutExpo 0.5"` |
| Custom curve | `"cubic-bezier(0.4, 0, 0.2, 1) 300ms"` |
| Spring | `"spring(300, 25)"` |
| Inertia | `"inertia(0.2, 400)"` |
| Keyframes | `"keyframes([0, 1.2, 1], [0, 0.5, 1]) 500ms"` |

Any form supports `delay(...)` and `repeat(n | infinite)`. Pass `animation={false}` to disable the reveal transition.

## Keyboard

| Key | Action |
| :-- | :-- |
| `Space` / `Enter` | Toggle the focused item |
| `↑` / `↓` | Move between triggers |
| `Home` / `End` | First / last trigger |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `accordion`, `accordion-item`, `accordion-trigger`, `accordion-content` |
| `data-state` | `open` \| `closed` |
| `data-orientation` | `vertical` |
| `data-disabled` | `true` |

## Accessibility

- Built on Radix Accordion, which follows the WAI-ARIA disclosure pattern.
- Triggers expose `aria-expanded` and `aria-controls` automatically.
- Keyboard: `Enter` and `Space` toggle an item; `ArrowUp` and `ArrowDown` move focus.
- Use descriptive trigger text, not icon-only headers.

## Best Practices

- **Keep content short per section.**
- **Use `type="single"` for FAQ-style lists.**
- **Use `type="multiple"` for settings panels.**
- **Reserve `defaultValue` for one item.**
