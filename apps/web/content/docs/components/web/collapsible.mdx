Collapsible reveals or hides a single panel triggered by a button. It is the primitive behind accordion rows and nested file trees.

## Motion

Collapsible accepts a `motion` prop on the root, inherited by `CollapsibleContent`. Pass a per-item override on `CollapsibleContent` to diverge from the root.

```tsx
<Collapsible motion="200 ease-out">
  <CollapsibleTrigger>Toggle</CollapsibleTrigger>
  <CollapsibleContent motion="300 cubic-bezier(0.4, 0, 0.2, 1)">Revealed content.</CollapsibleContent>
</Collapsible>
```

`motion` accepts `"off"`, `"150"`, `"150 ease-out"`, or `"150 cubic-bezier(0.4, 0, 0.2, 1)"`. The default is a 450ms smooth-out curve. `prefers-reduced-motion` wins and the reveal is instant.

## Keyboard

| Key | Action |
| :-- | :-- |
| `Space` / `Enter` | Toggle the panel |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `collapsible`, `collapsible-trigger`, `collapsible-content` |
| `data-state` | `open` \| `closed` |
| `data-disabled` | Present on disabled root, trigger, and content |

## Accessibility

- Triggers expose `aria-expanded` and `aria-controls`; content is labeled with `aria-labelledby` and carries `role="region"`.
- Keyboard: `Enter` and `Space` toggle the panel.
- Provide a descriptive trigger label or `aria-label`.

## Best Practices

- **Use for optional detail.** Content that must be visible on load belongs on the page.
- **Keep the trigger visible.** Never hide the trigger inside the content.
- **Default closed for long content.** Default open for short, always-relevant blocks.
- **Do not nest collapsibles.** Two levels is hard to track; use Accordion for nested groups.
