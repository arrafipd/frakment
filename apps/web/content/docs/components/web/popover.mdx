A floating panel anchored to a trigger. Opens on trigger click, closes on outside click or `Escape`. Position is resolved by Floating UI, so the panel flips and shifts automatically when it would overflow the viewport.

## Usage

```tsx title="popover.tsx"
import { Button } from "@/components/ui/button";
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@/components/ui/popover";
```

```tsx title="popover.tsx"
<Popover>
  <PopoverTrigger as={Button} variant="outline">Open</PopoverTrigger>
  <PopoverContent>
    Content
  </PopoverContent>
</Popover>
```

`PopoverTrigger` accepts `as` to render any component. Pass `as={Button}` for a styled trigger, or omit for a plain `<button>`.

`PopoverHeader`, `PopoverTitle`, and `PopoverDescription` wire `aria-labelledby` and `aria-describedby` onto the content automatically. Use them together so screen readers announce the panel correctly.

Pass `align` to control horizontal placement: `start`, `center` (default), or `end`. Pass `side` for `top`, `right`, `bottom` (default), or `left`.

## Form

Popover panels are not modal. They close on outside click, return focus to the trigger, and do not trap focus. For a focus-trapped experience, use `Dialog`.

## Motion

The panel fades and scales in through Frakment's motion engine. Pass `motion` on `PopoverContent`:

```tsx
<PopoverContent motion="200 ease-out">Content</PopoverContent>
```

`motion` accepts `"off"`, `"150"`, `"150 ease-out"`, or `"150 cubic-bezier(0.4, 0, 0.2, 1)"`. The default is a 150ms smooth-out curve. `prefers-reduced-motion` wins and the panel appears instantly.

## Accessibility

- `PopoverTrigger` sets `aria-haspopup="dialog"`, `aria-expanded`, and `aria-controls` on the trigger.
- `PopoverTitle` and `PopoverDescription` wire `aria-labelledby` and `aria-describedby` on the content when present.
- `Escape` closes the popover. Outside click closes the popover.
- Focus moves into the panel on open and returns to the trigger on close. Focus is not trapped.

## Best Practices

- **Pair a title with a description** when the panel shows form fields or structured content.
- **Use `align="start"`** for panels that should align with the trigger's leading edge, common in toolbars.
- **Keep content short.** Popover is not a modal. Long forms belong in `Dialog`.
