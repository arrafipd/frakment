## Usage

```tsx title="accordion.tsx"

  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
```

```tsx title="accordion.tsx"
<Accordion collapsible defaultValue="shipping" type="single">
  <AccordionItem value="shipping">
    <AccordionTrigger>What are your shipping options?</AccordionTrigger>
    <AccordionContent>
      Standard, express, and overnight options available.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## Motion

Accordion accepts a `motion` prop on the root, inherited by every content item. Pass a per-item override on `AccordionContent` to diverge from the root setting. Pass `motion="off"` or `motion={false}` to disable the reveal.

```tsx
<Accordion collapsible motion="200 ease-out" type="single">
  <AccordionItem value="a">
    <AccordionTrigger>Question</AccordionTrigger>
    <AccordionContent motion="300 cubic-bezier(0.4, 0, 0.2, 1)">Answer</AccordionContent>
  </AccordionItem>
</Accordion>
```

`motion` follows the same string syntax as every other Frakment component: `"off"`, `"150"`, `"150 ease-out"`, or `"150 cubic-bezier(0.4, 0, 0.2, 1)"`. The default is a 450ms smooth-out curve. `prefers-reduced-motion` always wins — the reveal is instant when the user has reduced motion enabled.

## Keyboard

| Key | Action |
| :-- | :-- |
| `Space` / `Enter` | Toggle the focused item |
| `↑` / `↓` | Move between triggers (vertical orientation) |
| `←` / `→` | Move between triggers (horizontal orientation) |
| `Home` / `End` | First / last trigger |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `accordion`, `accordion-item`, `accordion-header`, `accordion-trigger`, `accordion-content` |
| `data-state` | `open` \| `closed` |
| `data-orientation` | `vertical` \| `horizontal` |
| `data-disabled` | Present on disabled root, item, trigger, and content |

## Accessibility

- Follows the WAI-ARIA disclosure pattern. Triggers expose `aria-expanded` and `aria-controls`; content is labeled with `aria-labelledby` and carries `role="region"`.
- `AccordionTrigger` renders inside an `AccordionHeader` (`<h3>`). Keep trigger text descriptive so the landmark is announced correctly.
- Keyboard: `Enter` and `Space` toggle an item; arrow keys move focus between triggers; `Home` and `End` jump to the first or last trigger.
- Content stays in the DOM and is marked inert while closed, so screen readers skip it and Tab does not enter it.

## Best Practices

- **Keep content short per section.**
- **Use `type="single"` for FAQ-style lists.**
- **Use `type="multiple"` for settings panels.**
- **Reserve `defaultValue` for one item.**
