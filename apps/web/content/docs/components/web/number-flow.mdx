## Formatting

`value` goes through `Intl.NumberFormat` for locale-aware grouping, decimals, and percent. Pass `format`, `locales`, `prefix`, `suffix` to control the output.

<ComponentPreview name="number-flow-format" title="number-flow-format.tsx" src="examples/number-flow-format.tsx">
  <NumberFlowFormat />
</ComponentPreview>

```tsx
<NumberFlow value={12.5} format={{ style: "percent" }} />
<NumberFlow value={1234} prefix="$" />
<NumberFlow value={1234} suffix=" km" />
<NumberFlow value={1234} locales="de-DE" />
```

## Motion

By default, each digit slides with a 900ms "cubic-bezier(0.2, 0, 0.2, 1)" transition. Pass "motion" to override duration and easing.

<ComponentPreview name="number-flow-motion" title="number-flow-motion.tsx" src="examples/number-flow-motion.tsx">
  <NumberFlowMotion />
</ComponentPreview>

| Value | Result |
| :-- | :-- |
| omitted | 900ms "cubic-bezier(0.2, 0, 0.2, 1)" |
| "150" | 150ms default easing |
| "150ms" | 150ms default easing |
| "1s" | 1000ms default easing |
| "200 ease-out" | 200ms custom easing |
| "600 cubic-bezier(0.16, 1, 0.3, 1)" | 600ms custom cubic-bezier |
| "off" | No transition |

```tsx
<NumberFlow motion="200 ease-out" value={42} />
<NumberFlow motion="600 cubic-bezier(0.16, 1, 0.3, 1)" value={42} />
<NumberFlow motion="off" value={42} />
```

"prefers-reduced-motion: reduce" overrides every value. Third-party motion libraries that write inline styles to the element disable the internal transition automatically.

### Using your own animation library

Attach GSAP, Framer Motion, or the Web Animations API by writing inline styles to the element. The component detects the first external write and disables its own CSS transition automatically.

## Accessibility

- The outer element carries `aria-label` with the fully formatted value, so screen readers announce the number as a whole.
- Decorative spans are `aria-hidden="true"`.
- `prefers-reduced-motion: reduce` disables the slot transition.

## Best Practices

- **Keep values short.** Two to six digits animate cleanly.
- **Prefer prefix and suffix over concatenation.** Keeps screen reader announcements readable.
- **Use motion off when changing values rapidly.**
