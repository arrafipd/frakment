Dropdown Menu is a compound primitive built on Floating UI for positioning. It supports plain items, groups with labels, separators, nested submenus, checkbox / radio items, icons, and destructive variants.

## Usage

```tsx title="dropdown-menu.tsx"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger as={Button} variant="outline">
    Open
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Profile</DropdownMenuItem>
    <DropdownMenuItem>Settings</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

### Other parts

`DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuGroup`, `DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuShortcut`, `DropdownMenuSub`, `DropdownMenuSubTrigger`, `DropdownMenuSubContent`, `DropdownMenuPortal`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup`, `DropdownMenuRadioItem` — all ship in the same file and share the `data-slot` convention.

Adds `data-slot="dropdown-menu-*"` markers for styling hooks.

## Custom element

`DropdownMenuTrigger` accepts `as` to render a different root element or component. Pass `as={Button}` for a styled trigger, `as={Link}` for a router link, or omit for a plain `<button>`.

## Controlled

```tsx
const [open, setOpen] = React.useState(false)
<DropdownMenu open={open} onOpenChange={setOpen}>
  <DropdownMenuTrigger as={Button} variant="outline">
    Open
  </DropdownMenuTrigger>
  <DropdownMenuContent>{/* ... */}</DropdownMenuContent>
</DropdownMenu>
```

## Keyboard

| Key | Action |
| :-- | :-- |
| `Space` / `Enter` | Open, or activate focused item |
| `↑` / `↓` | Move focus |
| `→` / `←` | Open or close a submenu |
| `Home` / `End` | First / last item |
| `Esc` | Close |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `dropdown-menu-trigger`, `dropdown-menu-content`, `dropdown-menu-item`, `dropdown-menu-label`, `dropdown-menu-separator` |
| `data-state` | `open` \| `closed` |
| `data-highlighted` | `true` (focused item) |
| `data-disabled` | `true` |
| `data-side` | `top` \| `right` \| `bottom` \| `left` |

## Motion

The menu fades and scales in through Frakment's motion engine. Pass `motion` on `DropdownMenuContent`:

```tsx
<DropdownMenuContent motion="200 ease-out">Content</DropdownMenuContent>
```

`motion` accepts `"off"`, `"150"`, `"150 ease-out"`, or `"150 cubic-bezier(0.4, 0, 0.2, 1)"`. The default is a 150ms smooth-out curve. `prefers-reduced-motion` wins and the menu appears instantly.

## Accessibility

- The trigger must have `aria-label` when icon-only.
- Items are focusable; arrow keys move focus.
- Escape closes the menu and returns focus to the trigger.
- Destructive items are visually distinct but still focusable.

## Best Practices

- **Do not put more than 10 items.** Use a command palette for long lists.
- **Group related items.** `DropdownMenuSeparator` between clusters.
- **Destructive items last.** And always separated.
- **Keep labels verb-based.** "Delete", not "Deletion".
