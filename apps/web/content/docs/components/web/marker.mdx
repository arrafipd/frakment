### MarkerIcon

Extends `React.ComponentProps<"span">`. Renders `aria-hidden`. Sizes child SVG to 16px unless overridden.

### MarkerContent

Extends `React.ComponentProps<"span">`. Wraps inline links with underline and hover color. Add `className="shimmer"` for animated streaming text.

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `marker`, `marker-icon`, `marker-content` |
| `data-variant` | `default` \| `separator` \| `border` |

## Accessibility

- Pass `role="status"` to `Marker` when it announces a live change (typing, syncing, running).
- `MarkerIcon` is `aria-hidden` — the meaning lives in `MarkerContent`.
- For interactive markers, use `as="a"` for navigation and `as="button"` for actions so keyboard and screen readers behave correctly.
- With `prefers-reduced-motion`, the shimmer animation stops automatically.

## Best Practices

- **Use `variant="separator"` for inline status.** A horizontal rule with centered text reads as a divider.
- **Pair with an icon.** A spinner or check clarifies the state.
- **Keep text short.** "Thinking" beats "The model is currently thinking".
- **Announce with `role="status"`.** Screen readers announce updates politely.
