A select lets the user pick one option from a list. The listbox anchors to the trigger and aligns the selected item with the trigger label, matching native select behavior.

## Usage

```tsx title="select.tsx"
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";
```

```tsx title="select.tsx"
<Select>
  <SelectTrigger>
    <SelectValue placeholder="Pick a fruit" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="apple">Apple</SelectItem>
    <SelectItem value="banana">Banana</SelectItem>
  </SelectContent>
</Select>
```

## Position

By default the listbox uses `item-aligned` placement. The selected item overlaps the trigger so the list reads like a native select. Pass `position="popper"` to anchor the listbox under the trigger instead.

```tsx
<SelectContent position="popper" align="start" sideOffset={4}>
  <SelectItem value="apple">Apple</SelectItem>
</SelectContent>
```

`side`, `align`, `sideOffset`, and `alignOffset` only apply when `position="popper"`.

## Keyboard

| Key | Action |
| :-- | :-- |
| `Space` / `Enter` | Open the listbox when the trigger is focused. Select the focused item when the listbox is open. |
| `ArrowUp` / `ArrowDown` | Move focus to the previous / next item. |
| `Home` / `End` | Move focus to the first / last item. |
| `a`–`z` | Type-ahead. Jumps to the next item whose label starts with the typed prefix. |
| `Esc` | Close the listbox and return focus to the trigger. |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `select-trigger`, `select-value`, `select-content`, `select-viewport`, `select-group`, `select-label`, `select-item`, `select-item-text`, `select-separator` |
| `data-state` | `open` \| `closed` on the trigger and content. `checked` \| `unchecked` on items. |
| `data-highlighted` | Present on the focused item. |
| `data-disabled` | Present on disabled trigger and items. |
| `data-placeholder` | Present on the trigger when no value is selected. |
| `data-side` / `data-align` | Placement used by popper and item-aligned modes. |

## Motion

The listbox fades and scales in through Frakment's motion engine. Pass `motion` on `SelectContent`:

```tsx
<SelectContent motion="200 ease-out">Content</SelectContent>
```

`motion` accepts `"off"`, `"150"`, `"150 ease-out"`, or `"150 cubic-bezier(0.4, 0, 0.2, 1)"`. The default is a 150ms smooth-out curve. `prefers-reduced-motion` wins and the listbox appears instantly.

## Accessibility

- `SelectTrigger` exposes `role="combobox"`, `aria-haspopup="listbox"`, `aria-expanded`, and `aria-controls`. Do not set them manually.
- Pair the trigger with a `Label` or `FieldLabel` using `htmlFor` so screen readers announce the field name.
- Disabled items stay visible but are skipped by keyboard navigation and type-ahead.
- `Escape` closes the listbox. Outside pointer down also closes it.
- Focus moves to the selected item on open and returns to the trigger on close.

## Best Practices

- Use select for five or more options. Fewer options belong in a radio group.
- Always provide a placeholder. `SelectValue placeholder` keeps the empty state legible.
- Group long lists. `SelectGroup` and `SelectLabel` help users scan by category.
- Prefer `popper` for toolbars. The anchored list feels native inside forms; popper reads better alongside inline controls.
