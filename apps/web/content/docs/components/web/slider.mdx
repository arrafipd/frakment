## Anatomy

```tsx
<Slider defaultValue={[50]} max={100} step={1} />
```

- **Root** — flex container, horizontal or vertical
- **Track** — muted rail behind the fill
- **Range** — filled portion between min and the current value(s)
- **Thumb** — draggable handle, one per value

## States

| State | How |
| :-- | :-- |
| Single | `defaultValue={[50]}` |
| Range | `defaultValue={[25, 75]}` |
| Multi | `defaultValue={[10, 20, 70]}` |
| Vertical | `orientation="vertical"` |
| Disabled | `disabled` prop |

## Keyboard

| Key | Action |
| :-- | :-- |
| `←` / `→` | Decrease / increase value |
| `↑` / `↓` | Decrease / increase value |
| `Home` / `End` | Min / max |
| `Page Up` / `Page Down` | Step × 10 up / down |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `slider`, `slider-track`, `slider-range`, `slider-thumb` |
| `data-orientation` | `horizontal` \| `vertical` |
| `data-disabled` | `true` |

## Accessibility

- Every thumb renders `role="slider"` with `aria-valuemin`, `aria-valuemax`, and `aria-valuenow`.
- Each thumb is keyboard focusable and responds to arrow keys, Home, End, Page Up, and Page Down.
- `aria-orientation` is set on each thumb.
- Pair the slider with a `Label` when the slider is not self-describing.

## Best Practices

- **Show the current value.** A slider without a visible number or label is hard to read. Pair it with a formatted span.
- **Prefer ranges when both ends matter.** Use two thumbs for temperature, price, or scale intervals.
- **Add a label.** Link a `Label` with `htmlFor` to the slider `id` so screen readers announce it.
- **Do not replace a numeric input.** Sliders are imprecise for exact values. Pair with a number input when precision matters.
