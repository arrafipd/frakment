Sheet renders a modal panel that slides in from a screen edge. Focus is trapped, Escape dismisses, and the backdrop closes on click.

## Usage

~~~tsx title="sheet.tsx"

<DocsBaseSwitcher base="web" component="sheet" className="mb-6" />

  SheetFooter, SheetHeader, SheetTitle, SheetTrigger,
} from "@/components/ui/sheet";
~~~

~~~tsx
<Sheet>
  <SheetTrigger as={Button}>Open</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Title</SheetTitle>
      <SheetDescription>Description</SheetDescription>
    </SheetHeader>
    <SheetFooter>
      <SheetClose as={Button} variant="outline">Close</SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>
~~~

## As Prop

`SheetTrigger` and `SheetClose` accept an `as` prop to render a custom element, for example `as={Button}` or `as="a"`.

## Controlled

```tsx
const [open, setOpen] = React.useState(false)
<Sheet open={open} onOpenChange={setOpen}>
  <SheetTrigger as={Button}>Open</SheetTrigger>
  <SheetContent side="right">{/* ... */}</SheetContent>
</Sheet>
```

## Keyboard

| Key | Action |
| :-- | :-- |
| `Esc` | Close the sheet |
| `Tab` | Move focus |
| `Shift + Tab` | Move focus backwards |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `sheet-trigger`, `sheet-content`, `sheet-header`, `sheet-footer`, `sheet-title`, `sheet-description`, `sheet-close` |
| `data-state` | `open` \| `closed` |
| `data-side` | `top` \| `right` \| `bottom` \| `left` |

## Accessibility

- Focus is trapped inside the sheet while open.
- `SheetTitle` and `SheetDescription` are announced to screen readers.
- `Escape` closes the sheet unless prevented.
- Clicking the backdrop closes the sheet.

## Best Practices

- **Use for navigation, not for data entry.** Long forms belong on a page.
- **Keep the side consistent.** `right` for navigation, `bottom` for mobile menus.
- **Close on link click.** Otherwise the sheet sits between the user and the destination.
- **Do not stack sheets.** One at a time.
