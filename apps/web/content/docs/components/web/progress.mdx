### ProgressLabel

Extends `React.ComponentProps<"span">`. Renders the label on the left of the header row.

### ProgressValue

Extends `React.ComponentProps<"span">`. Reads `value` from `ProgressContext` and renders `{value}%`.

## Motion

The indicator uses a CSS `transition-transform` (500ms ease-out) by default. Override with `motion`:

```tsx
<Progress motion="300 cubic-bezier(0.34, 1.56, 0.64, 1)" value={60} />
```

| Value | Result |
| :-- | :-- |
| omitted | 500ms ease-out |
| `"200"` | 200ms ease-in-out |
| `"500 cubic-bezier(...)"` | 500ms custom easing |
| `"off"` | instant (no transition) |

When `prefers-reduced-motion` is set, the transition is disabled regardless of the value. Third-party animation libraries that write inline styles to the indicator automatically suppress the internal CSS transition.

## Accessibility

- Renders `<div role="progressbar">` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` managed automatically.
- Pass `aria-label` when the progress is not self-describing (bar without `ProgressLabel`).
- Do not rely on color alone. Use `ProgressValue` to show the numeric value.

## Anatomy

```tsx
<Progress value={60}>
  <ProgressLabel />
  <ProgressValue />
</Progress>
```

- **Root** — track background
- **Indicator** — filled portion driven by `value`
- **Label** — left-aligned heading, optional
- **Value** — right-aligned percentage

## Best Practices

- **Always show the value.** A bar alone is ambiguous.
- **Use determinate for known tasks.** Spinners for unknown.
- **Keep animation under 1s.** 500ms ease-out default.
- **Cap at 100.** Values above `max` are clamped.
