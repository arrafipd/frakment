Item is a flexible row primitive for grouping media, content, and actions. Use it for settings lists, activity feeds, user rows, or any horizontal layout with a leading visual and trailing controls.

### ItemMedia / ItemContent / ItemTitle / ItemDescription / ItemActions

Extend `React.ComponentProps<"div">`. Each maps to a `data-slot` attribute for CSS targeting.

## As prop

`Item` also accepts an `as` prop to render a custom element such as `<a>` or `<li>`.

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `item`, `item-group`, `item-media`, `item-content`, `item-title`, `item-description`, `item-actions` |
| `data-variant` | `default` \| `outline` \| `muted` |
| `data-size` | `default` \| `sm` |

## Accessibility

- `Item` renders a `<div>` — for interactive rows, use `as` with `<a>` or `<button>` so keyboard and screen readers work.
- `ItemMedia` should be `aria-hidden` when the visual is decorative (e.g., a status dot).
- `ItemTitle` is a visual text container, not a labeling relationship. Ensure each interactive link or button has its own accessible name.

## Best Practices

- **Use for list rows with mixed content.** Media + content + actions fits in one Item.
- **Keep the media square.** A 32px to 40px square reads as an avatar or icon.
- **Actions belong in `ItemActions`.** Do not float buttons inside content.
- **One action cluster.** More than three actions belong in a dropdown.
