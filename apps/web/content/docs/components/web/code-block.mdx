## Accessibility

- **CodeBlockContent** has `tabIndex={0}` for keyboard scroll.
- **CodeBlockCopyButton** has `aria-label` and a `aria-live` region announcing "Copied".
- Use **CodeBlockTitle** as the accessible name of the block.

## Composition

```text
CodeBlock
├── CodeBlockHeader
│   ├── CodeBlockTitle
│   └── CodeBlockActions
├── CodeBlockContent
├── CodeBlockCopyButton
└── CodeBlockFooter
```

## Best Practices

- **Set a max-height.** Long files push the layout.
- **Show the file name.** Users need to know where the code goes.
- **Copy action on hover, not always.** Reduces visual noise.
- **Do not highlight unknown languages.** Fall back to plain text.
