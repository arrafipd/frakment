Spinner renders a loading indicator. It carries `role="status"` and `aria-label="Loading"` so screen readers announce a live state. Two shapes are available: `default` (a circular arc, rendered as CSS border for zero rotation jitter) and `spoke` (a sunburst, from `LoaderIcon`).

Extends `React.ComponentProps<"span">`. Defaults: `size-4`, `animate-spin`, `role="status"`, `aria-label="Loading"`.

## Accessibility

- Renders `role="status"` and `aria-label="Loading"` by default — screen readers treat it as a live region.
- Pair with visible text for clarity when the loading state has semantic meaning.
- `animate-spin` respects `prefers-reduced-motion` via `motion-reduce:animate-none`.
- When placed inside `Button` or `Badge`, keep `data-icon="inline-start"` or `"inline-end"` so the gap matches the surrounding component.

## Best Practices

- **Pair with text.** A spinner alone is ambiguous.
- **Do not block the whole page.** Use a skeleton for content areas.
- **Respect reduced motion.** When `prefers-reduced-motion` is set, the icon renders static.
- **Hide after success.** A lingering spinner reads as "still loading".
