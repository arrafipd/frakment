## Usage

```tsx title="avatar.tsx"
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";
```

```tsx title="avatar.tsx"
<Avatar>
  <AvatarImage src="/avatars/me.avif" alt="@me" />
  <AvatarFallback>{"ME"}</AvatarFallback>
</Avatar>
```

Pass `grayscale` through `className` to desaturate. Demo assets follow a `-l` (facing left) and `-r` (facing right) convention — pick one per row.

## Group

**AvatarGroup** overlaps avatars with a 2px background ring between each one, keeping the stack readable. Place **AvatarGroupCount** as the last child to show how many more are hidden, and **AvatarBadge** inside an **Avatar** to indicate presence. Swap to right-to-left stacking with `className="flex-row-reverse"`.

## API Reference

### Avatar

<PropsTable
  rows={[
    {
      name: "size",
      type: "sm | default | lg",
      default: "default",
      description: "Controls the diameter of the avatar (24px / 32px / 40px).",
    },
  ]}
/>

### AvatarImage

Renders the avatar image. Requires `src` and `alt`. Applies `object-cover` and `rounded-full`. Hidden until the image finishes loading, so the fallback shows first.

### AvatarFallback

Renders children when the image is missing, still loading, or fails. Use 2–3 character initials.

### AvatarBadge

Extends `React.ComponentProps<"span">`. Positioned absolutely at the bottom-right. Pass a background color with `className` (e.g., `bg-green-600`).

### AvatarGroup / AvatarGroupCount

Extend `React.ComponentProps<"div">`. Group applies `-space-x-2` and a 2px background ring per avatar. Count inherits the size of the group's avatars via `has-data-[size=lg]`.

## Accessibility

- Always pass `alt` on **AvatarImage** — describe the person, not the file. Use `@username` for handles.
- **AvatarFallback** initials act as a visual label but are not read as a name. If the avatar has semantic meaning, wrap the group in a container with `aria-label`.
- **AvatarBadge** is decorative. Convey the status in text when it matters (e.g., "Online").
- **AvatarGroup** should have an accessible label like `aria-label="3 participants"` when it summarizes a list.

## Best Practices

- **Always include a fallback.** `AvatarFallback` renders when the image fails or is missing.
- **Size by context.** 24px in lists, 40px in headers, 64px in profiles.
- **Add an accessible name.** Wrap in a button with `aria-label` when clickable.
- **Do not rely on the image alone.** Pair with the user's name or a tooltip.
