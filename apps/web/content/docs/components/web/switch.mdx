## Controlled

```tsx
const [checked, setChecked] = React.useState(false);
<Switch checked={checked} onCheckedChange={setChecked} />
```

## Motion

The thumb slides with a CSS `transition-transform` by default. Override with `motion` without editing the file:

```tsx
<Switch motion="300 cubic-bezier(0.34, 1.56, 0.64, 1)" />
```

| Value | Result |
| :-- | :-- |
| omitted | Tailwind default transition |
| `"200"` | 200ms ease-in-out |
| `"300 cubic-bezier(...)"` | 300ms custom easing |
| `"off"` | no transition |

When `prefers-reduced-motion` is set, the transition is disabled regardless of the value. Third-party animation libraries that write inline styles to the thumb automatically suppress the internal CSS transition.

## Accessibility

- Renders `<button role="switch">` with `aria-checked` managed automatically. Do not add `role` manually.
- Pair with a `<Label>` or `FieldLabel` using `htmlFor`.
- The visual state (on/off) is conveyed by position and color. The accessible state is conveyed by `aria-checked`.
- `disabled` removes the switch from the tab order.

## Best Practices

- **Use Switch for instant toggles.** If the change requires a Save button, use Checkbox.
- **Do not use "On" / "Off" labels.** The state is visible in the track.
- **Keep the label short.** A phrase, not a sentence.
- **Group related switches** under a heading rather than scattering them.
- **Do not use Switch for a destructive action.** Use a Dialog confirmation.
