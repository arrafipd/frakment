| Variant | Use case |
| :-- | :-- |
| `default` | Primary action |
| `secondary` | Secondary action |
| `outline` | Bordered neutral |
| `ghost` | Minimal, hover only |
| `destructive` | Irreversible action |
| `link` | Inline link styling |

## Size & Icon Size

Use the `size` prop to control the dimensions of a text button.

<ComponentPreview name="button-size" title="button-size.tsx" src="examples/button-size.tsx">
  <ButtonSize />
</ComponentPreview>

| Size      | Height | Padding |
| :-------- | :----- | :------ |
| `xs`      | 28px   | `px-2`  |
| `sm`      | 32px   | `px-3`  |
| `default` | 36px   | `px-4`  |
| `lg`      | 40px   | `px-6`  |

Icon sizes use the same `size` prop. Pass `size="icon-xs"`, `"icon-sm"`, `"icon"`, or `"icon-lg"` for a square button that fits a single icon.

| Size      | Dimensions |
| :-------- | :--------- |
| `icon-xs` | 28×28      |
| `icon-sm` | 32×32      |
| `icon`    | 36×36      |
| `icon-lg` | 40×40      |

## Motion

By default the button uses Tailwind's `transition-all` (150ms, `ease-in-out`). Pass `motion` to override the transition without editing the file.

### Default

<ComponentPreview name="button-motion-default" src="examples/button-motion-default.tsx" title="button-motion-default.tsx">
  <ButtonMotionDefault />
</ComponentPreview>

### Reduced motion

`prefers-reduced-motion: reduce` disables the transition automatically. The first button below opts out with `className="transition-none"`. The second uses the default and respects the OS setting.

<ComponentPreview name="button-motion-reduced" src="examples/button-motion-reduced.tsx" title="button-motion-reduced.tsx">
  <ButtonMotionReduced />
</ComponentPreview>

### Value reference

| Value | Result |
| :-- | :-- |
| omitted | Tailwind `transition-all` (150ms ease-in-out) |
| `"150"` | 150ms ease-in-out |
| `"200 cubic-bezier(0.16, 1, 0.3, 1)"` | 200ms custom easing |

```tsx
<Button motion="300 ease-out">Slow reveal</Button>
```

To remove the default transition without a motion value, pass `className="transition-none"`. This is not a `motion` prop value — it is a Tailwind utility that wins over the base class.

### Using your own animation library

Attach GSAP, Framer Motion, the Web Animations API, or any library that writes inline styles to the element. The component detects the first external write and disables its own CSS transition automatically. No extra prop is required.

```tsx
const ref = useRef<HTMLButtonElement>(null);

useEffect(() => {
  gsap.to(ref.current, { scale: 1.1, duration: 0.3 });
}, []);

<Button ref={ref}>Animated by GSAP</Button>
```

CSS class changes such as hover styles do not trigger the guard. Only inline style writes from a library or a manual ref assignment do.

## Links & Router links

A button can navigate. Use `href` for a static anchor, or `as` to render a router link. The first button below is a static `<a>`; the second is a Next.js `<Link>` rendered with button styles.

<ComponentPreview name="button-anchor" title="button-anchor.tsx" src="examples/button-anchor.tsx">
  <ButtonAnchor />
</ComponentPreview>

Static link:

```tsx
import { Button } from "@/components/ui/button";

<Button href="/pricing" variant="outline">Pricing</Button>
```

Router link:

```tsx
import Link from "next/link";
import { Button } from "@/components/ui/button";

<Button as={Link} href="/pricing" variant="outline">Pricing</Button>
```

Custom component:

```tsx
<Button as={MyLink} to="/pricing" variant="outline">Pricing</Button>
```

### Which approach to pick

| Case | Approach |
| --- | --- |
| Static site, plain HTML, external URL | `<Button href="...">` |
| Next.js, React Router, TanStack Router | `<Button as={Link} href="...">` |
| Custom component with its own props | `<Button as={CustomComponent}>` |
| Triggers an action, not navigation | `<Button onClick={...}>` |

### buttonVariants

The `buttonVariants` helper returns the class string for any variant and size. Use it to apply button styles to a router link component.

```tsx
import { buttonVariants } from "@/lib/utils";

<a className={buttonVariants({ variant: "outline", size: "sm" })} href="/docs">
  Read the docs
</a>
```

## Accessibility

- Set `type="button"` on buttons that are not intended to submit a form.
- Provide an `aria-label` on icon-only buttons.
- `disabled` removes the button from the tab order.
- Color contrast is maintained by design tokens. Run your own contrast check for custom tokens.

## Best Practices

- **Use one primary button per surface.**
- **Prefer `size="sm"` inside toolbars.**
- **Never rely on color alone.**
- **Use `href` for static links, `as={Link}` for router links.**
- **Reserve `destructive` for irreversible actions.**
