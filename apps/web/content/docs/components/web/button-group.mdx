Groups adjacent buttons into a single visual unit. Buttons inside a group share borders and outer corners so they read as one control. Works with `Button`, `Input`, `Select`, `DropdownMenu`, and anything that renders `[data-slot]`.

## Accessibility

- `ButtonGroup` sets `role="group"` and `data-orientation` on the root div, so screen readers announce the grouped context.
- Children keep their own roles and labels. The group does not override them.
- Icon-only buttons inside the group still need an `aria-label` on the button itself, not on the group.

## Best Practices

- **Group actions that belong to the same task.** Archive and Report belong together. Archive and Delete do not.
- **Keep group size uniform.** Mixing `sm` and `lg` inside a group reads as a bug, not a feature.
- **Use `ButtonGroupSeparator` sparingly.** The default border merge is enough for most cases.
- **Nested groups need an outer ButtonGroup.** The outer wrapper adds the gap and keeps the composition readable.
