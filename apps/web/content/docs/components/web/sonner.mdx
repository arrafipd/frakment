## Promise

`toast.promise` switches the message as a promise resolves or rejects.

<ComponentPreview name="sonner-promise" title="sonner-promise.tsx" src="examples/sonner-promise.tsx" previewClassName="h-auto py-16">
  <SonnerPromise />
</ComponentPreview>

~~~tsx
toast.promise(createEvent(), {
  loading: "Creating event…",
  success: (d) => \`\${d.name} created\`,
  error: "Could not create",
});
~~~

## Custom position

Default position is responsive: `top-center` on mobile and `bottom-right` on desktop. Override per toast with `position`, or set a fixed position on `<Toaster position="..." />` to disable responsive behavior.

<ComponentPreview name="sonner-position" title="sonner-position.tsx" src="examples/sonner-position.tsx" previewClassName="h-auto py-16">
  <SonnerPosition />
</ComponentPreview>

~~~tsx
toast("Saved", { position: "top-left" })
~~~

## Motion

Toasts animate with CSS transitions: enter, exit, and height use 400ms ease, and swipe-out uses 200ms. Pass `motion` on `<Toaster>` to override duration and easing without editing the file:

~~~tsx
<Toaster motion="200 cubic-bezier(0.22, 1, 0.36, 1)" />
~~~

| Value | Result |
| :-- | :-- |
| omitted | 400ms ease (default) |
| `"200"` | 200ms ease-in-out |
| `"200 ease-out"` | 200ms custom easing |
| `"300 cubic-bezier(...)"` | 300ms custom cubic-bezier |
| `"off"` | no transition |

When `prefers-reduced-motion` is set, the transition is disabled regardless of the value.

### Using your own animation library

The CSS engine lives inside `sonner.tsx` as the `sonnerStyles` constant. To swap it for GSAP, Framer Motion, or the Web Animations API, edit that constant and the `Toast` render function directly. The `motion` prop covers CSS transitions only; a third-party engine bypasses it entirely.

## Accessibility

- Each toast is announced via `aria-live="polite"`.
- Errors use `aria-live="assertive"` automatically.
- Dismiss with `toast.dismiss()` or the close button when enabled.

## Anatomy

```tsx title="sonner.tsx"
import { Toaster, toast } from "@/components/ui/sonner";

<Toaster />
toast("Saved");
```

- **Toaster** — fixed viewport stack, rendered once near the root
- **Toast** — a single notification with title, description, and optional action

## Best Practices

- **One Toaster per app.** Nesting causes duplicate stacks.
- **Keep messages short.** Title fits in one line.
- **Use `toast.error` for failures.** Do not use `toast` with custom styles.
- **Auto-dismiss after 4 seconds.** Persistent toasts need an explicit close.
