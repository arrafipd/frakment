A div-based divider. Horizontal by default, vertical with `orientation="vertical"`. When `decorative` is true (the default) it renders with `role="none"`. Set `decorative={false}` when the divider carries structural meaning and should be announced to assistive tech.

```tsx

```

## Semantic

<ComponentPreview name="separator-decorative" title="separator-decorative.tsx" src="examples/separator-decorative.tsx">
  <SeparatorDecorative />
</ComponentPreview>

`decorative={false}` renders `role="separator"` with `aria-orientation`. Use it when the divider communicates structure that a screen reader should announce. Default `true` hides the divider from the accessibility tree.

```tsx
<Separator decorative={false} />;
```

## Accessibility

- Default `decorative={true}` renders `role="none"`, so screen readers skip the divider.
- `decorative={false}` renders `role="separator"` and `aria-orientation` so the divider becomes part of the document structure.
- Do not attach `aria-label` to a decorative separator. It is invisible to assistive tech by design.

## Best Practices

- **Use decorative by default.** Only opt into `decorative={false}` when the divider encodes structural meaning.
- **Prefer spacing over separators.** Gap or padding on the parent often reads better than a hard line.
- **Keep vertical separators short.** They work best inside inline rows (navigation, breadcrumbs, meta info).
