## Usage

```tsx title="tooltip.tsx"

  Tooltip,
  TooltipContent,
  TooltipTrigger,

```

```tsx

  <TooltipTrigger as={Button} variant="outline">Hover</TooltipTrigger>
  <TooltipContent>Add to library</TooltipContent>
</Tooltip>
```

## Motion

The tooltip fades in with a default `120ms ease-out` transition. Override with `motion`:

```tsx
<TooltipContent motion="200 ease-out">Read more</TooltipContent>
```

| Value | Result |
| :-- | :-- |
| omitted | 120ms ease-out |
| `"200"` | 200ms ease-in-out |
| `"300 cubic-bezier(...)"` | 300ms custom easing |
| `"off"` | instant (no transition) |

When `prefers-reduced-motion` is set, the transition is disabled. Inline style changes to the tooltip automatically suppress the internal CSS transition.

## Keyboard

| Key | Action |
| :-- | :-- |
| `Tab` | Focus the trigger, opens the tooltip |
| `Esc` | Close the tooltip |

| Attribute | Values |
| :-- | :-- |

| `data-state` | `open` \| `closed` |
| `data-side` | `top` \| `right` \| `bottom` \| `left` |
| `data-align` | `start` \| `center` \| `end` |

## Accessibility

- The trigger receives `aria-describedby` pointing to the tooltip content id when open.
- Tooltip content renders `role="tooltip"`.
- Icon-only triggers need `aria-label`; the tooltip is supplementary text.
- Keyboard: `Tab` opens on focus, `Esc` closes.

## Best Practices

- **Never put essential text in a tooltip.** Use a visible label.
- **Keep it short.** A phrase, not a sentence.
- **Do not stack tooltips.** One open at a time.
- **Wrap around a real element.** Use `as={Button}` or `as={Link}` so the trigger is focusable.
