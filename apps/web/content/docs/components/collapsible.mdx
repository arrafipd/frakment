## Animation

Collapsible accepts an `animation` prop on the root, inherited by `CollapsibleContent`.

```tsx
<Collapsible animation="spring(300, 25)">
  <CollapsibleTrigger>Toggle</CollapsibleTrigger>
  <CollapsibleContent>Revealed content.</CollapsibleContent>
</Collapsible>
```

| Form | Example |
| :-- | :-- |
| Named easing | `"easeInOut"`, `"easeOutExpo"`, `"easeSmoothOut"` |
| Named easing + duration | `"easeInOut 300ms"`, `"easeOutExpo 0.5"` |
| Custom curve | `"cubic-bezier(0.4, 0, 0.2, 1) 300ms"` |
| Spring | `"spring(300, 25)"` |
| Inertia | `"inertia(0.2, 400)"` |
| Keyframes | `"keyframes([0, 1.2, 1], [0, 0.5, 1]) 500ms"` |

Any form supports `delay(...)` and `repeat(n | infinite)`. Pass `animation={false}` to disable the reveal transition.

| :-- | :-- |

## Accessibility

- Built on Radix Collapsible; exposes `aria-expanded` and `aria-controls`.
- Keyboard: `Enter` and `Space` toggle the panel.
- Provide a descriptive trigger label or `aria-label`.

## Best Practices

- **Use for optional detail.** Content that must be visible on load belongs on the page.
- **Keep the trigger visible.** Never hide the trigger inside the content.
- **Default closed for long content.** Default open for short, always-relevant blocks.
- **Do not nest collapsibles.** Two levels is hard to track; use Accordion for nested groups.
