## Size

Use the `size` prop to control the dimensions of a text button.

The preview above renders at the web size scale. On iOS and Android the component applies the larger values in the table below, sized to meet touch target guidance.

<ComponentPreview name="native/button-size" title="button-size.tsx" src="../../apps/native/examples/button-size.tsx">
  <NativeButtonSize />
</ComponentPreview>

| Size | Height | Padding |
| :--- | :----- | :------ |
| `xs` | 40dp | `px-4` |
| `sm` | 44dp | `px-5` |
| `default` | 48dp | `px-6` |
| `lg` | 51dp | `px-8` |

### Icon size

Icon buttons use a separate size system. Each produces a square button sized to fit its icon.

| Size | Dimensions |
| :--- | :--------- |
| `icon-xs` | 40×40 |
| `icon-sm` | 44×44 |
| `icon` | 48×48 |
| `icon-lg` | 51×51 |

## Icons & With Icons

Buttons accept an icon next to a label or render as a square icon-only button. Icons are sized by `[&_svg]:size-4`. Provide the icon as a child of the button.

## Accessibility

- The component sets `accessibilityRole="button"` on the underlying `Pressable`.
- The `disabled` prop sets `accessibilityState={{ disabled: true }}`.
- Provide `accessibilityLabel` on icon-only buttons.
- Press feedback uses `onPressIn` and `onPressOut`, not hover.

## Best Practices

- **Use one primary button per screen.**
- **Prefer `size="default"` or larger for touch-critical actions.**
- **Never rely on color alone.**
- **Provide `accessibilityLabel` on icon-only buttons.**
- **Reserve `destructive` for irreversible actions.**

## Platform notes

- **Press, not hover.** Native devices have no hover state. The button renders its pressed state through `onPressIn` and `onPressOut`.
- **No anchor mode.** React Native has no `<a>` element. Use the router link from `expo-router` for navigation, and style it with the exported `buttonVariants` helper.
- **No `motion` prop.** The web Button exposes a `motion` prop for CSS transition overrides. Native does not need it because press feedback is instant and driven by the platform.
- **Touch target.** Visual size equals tap area. The `default` and `lg` sizes meet the 44dp minimum guidance on iOS and the 48dp guidance on Android. For `xs` and `sm`, prefer a larger size for touch-critical actions.
