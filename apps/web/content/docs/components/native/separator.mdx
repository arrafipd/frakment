A `View`-based divider. Horizontal by default, vertical with `orientation="vertical"`. The color comes from `useThemeColors().border`, so it tracks light and dark mode without extra configuration.

Pass `orientation="vertical"`. The divider sets width to 1px and stretches to fill its parent height. Use it inside a `flex-row` container.

```tsx
<View className="h-6 flex-row items-center gap-4">
  <Text>Docs</Text>
  <Separator orientation="vertical" />
  <Text>Source</Text>
</View>
```

## Decorative

<ComponentPreview name="native/separator-decorative" title="separator-decorative.tsx" src="../../apps/native/examples/separator-decorative.tsx">

Default `decorative` is `true`, matching web behavior. Pass `decorative={false}` to expose the divider to assistive tech. Native does not render a visible difference. Only the accessibility hint changes.

## Accessibility

- Default `decorative` is `true`, so the divider is hidden from screen readers. Set `decorative={false}` when the divider carries structural meaning.
- The divider has no text content. No `accessibilityLabel` is needed.
- Native does not expose `aria-orientation`. Orientation is visual only.

## Best Practices

- **Prefer the default horizontal divider.** Vertical dividers are harder to hit with a finger and rarely needed in touch layouts.
- **Do not use a separator as a margin trick.** Use `gap` or `padding` on the parent `View` instead.
- **Keep separators one-pixel.** The 1px width and height match the web component. Scaling beyond 1px reads as a border, not a divider.

## Platform notes

- **No `<hr>` element.** React Native renders the separator as a `View` with a 1px height or width.
- **No `motion` prop.** The separator does not animate. Web also does not animate it, so behavior matches.
- **Color comes from the theme.** The web version uses the `border` CSS variable. Native reads `useThemeColors().border`, so the resolved color matches across platforms.
