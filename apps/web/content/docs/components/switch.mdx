## Accessibility

- `Switch` renders a button with `role="switch"` and manages `aria-checked`. Do not add `role` manually.
- Pair with a `label` or `FieldLabel` using `htmlFor`.
- The visual state (on/off) is conveyed by position and color. The accessible state is conveyed by `aria-checked`.
- `disabled` removes the switch from the tab order.

## Best Practices

- **Use Switch for instant toggles.** If the change requires a Save button, use Checkbox.
- **Do not use "On" / "Off" labels.** The state is visible in the track.
- **Keep the label short.** A phrase, not a sentence.
- **Group related switches** under a heading rather than scattering them.
- **Do not use Switch for a destructive action.** Use a Dialog confirmation.
