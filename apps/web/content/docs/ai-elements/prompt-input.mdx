Prompt Input is a composer for chat and agent surfaces. Attachment chips sit above a textarea, and a bottom bar holds the attach action, a model picker, an effort picker, and the send button.

Prompt Input is a **composition**, not a primitive. It composes [InputGroup](/docs/components/input-group), [Attachment](/docs/components/attachment), [Dropdown Menu](/docs/components/dropdown-menu), and [Button](/docs/components/button).

## Anatomy

~~~tsx title="prompt-input.tsx"
<InputGroup>
  <InputGroupAddon align="block-start">
    <Attachment>
      <AttachmentMedia />
      <AttachmentContent>
        <AttachmentTitle />
      </AttachmentContent>
      <AttachmentActions>
        <AttachmentAction />
      </AttachmentActions>
    </Attachment>
  </InputGroupAddon>
  <InputGroupTextarea />
  <InputGroupAddon align="block-end">
    <InputGroupButton />
    <DropdownMenu>
      <DropdownMenuTrigger />
      <DropdownMenuContent>
        <DropdownMenuRadioGroup>
          <DropdownMenuRadioItem />
        </DropdownMenuRadioGroup>
      </DropdownMenuContent>
    </DropdownMenu>
    <InputGroupButton type="submit" />
  </InputGroupAddon>
</InputGroup>
~~~

- **InputGroup** — the bordered composer surface
- **InputGroupAddon** — top row for attachments, bottom row for actions
- **InputGroupTextarea** — the multi-line input, grows with content
- **InputGroupButton** — pill-shaped action buttons for attach, model, effort, send
- **Attachment** — compact file chip with media, title, and a remove action

## Attachments

Files selected with a hidden `<input type="file">` are stored in component state and rendered as chips in the top addon. Each chip exposes an `AttachmentAction` for removal. The top addon uses `align="block-start"` and `flex-wrap` so chips wrap on narrow widths.

## Pickers

Model and effort use `DropdownMenuRadioGroup`. The trigger is an `InputGroupButton` wrapped with `asChild`, which preserves the composer styles. Radix closes the menu on select, no extra handler needed.

## Send state

The send button uses `disabled={!canSend}`. When disabled it renders with the muted background from the Button primitive, keeping the icon readable against the composer instead of fading out.

## Accessibility

- Every `InputGroupButton` carries an `aria-label` (`Attach files`, `Model: GPT-5`, `Effort: Medium`, `Send`).
- The file input is `sr-only` and triggered by the attach button.
- The attach chip remove action is labelled per file (`Remove report.pdf`).
- Enter submits, Shift+Enter inserts a newline.

## Best Practices

- **Keep the picker set small.** Model and effort are enough. A third picker crowds the bar.
- **Show attachments before send.** Users want to confirm what is going out.
- **Disable, do not hide the send button.** Hidden sends leave no affordance to aim at.
- **Use `asChild` on picker triggers.** Wrapping the `InputGroupButton` keeps the shared styles.
