Model Selector is a composer with two dropdowns for picking the model and the reasoning effort. It composes InputGroup, DropdownMenu, and Button so the pickers sit inside the same bordered surface as the textarea and the send action.

Model Selector is a **composition**, not a primitive. Install the three primitives it uses, then wire it the same way the demo does.

## Usage

```tsx title="model-selector.tsx"
import { InputGroup, InputGroupAddon, InputGroupButton, InputGroupTextarea } from "@/components/ui/input-group";
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuLabel,
  DropdownMenuRadioGroup,
  DropdownMenuRadioItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";

<InputGroup>
  <InputGroupTextarea value={text} onChange={...} />
  <InputGroupAddon align="block-end">
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <InputGroupButton size="sm" variant="outline">
          {currentModel.name}
        </InputGroupButton>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuRadioGroup value={model} onValueChange={setModel}>
          <DropdownMenuRadioItem value="gpt-5">GPT-5</DropdownMenuRadioItem>
        </DropdownMenuRadioGroup>
      </DropdownMenuContent>
    </DropdownMenu>
    <InputGroupButton type="submit" disabled={!canSend}>
      <ArrowUpIcon />
    </InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```

## Anatomy

```tsx title="model-selector.tsx"
<InputGroup>
  <InputGroupTextarea />
  <InputGroupAddon align="block-end">
    <InputGroupButton type="button" aria-label="Attach"><PlusIcon /></InputGroupButton>
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <InputGroupButton size="sm" variant="outline">{model}</InputGroupButton>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuRadioGroup>...</DropdownMenuRadioGroup>
      </DropdownMenuContent>
    </DropdownMenu>
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <InputGroupButton size="sm" variant="outline">{effort}</InputGroupButton>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuRadioGroup>...</DropdownMenuRadioGroup>
      </DropdownMenuContent>
    </DropdownMenu>
    <InputGroupButton type="submit" aria-label="Send"><ArrowUpIcon /></InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```

- **InputGroup** — bordered surface holding the textarea and the addon.
- **InputGroupTextarea** — the composer input. Enter sends, Shift+Enter inserts a newline.
- **InputGroupAddon align="block-end"** — bottom row of actions.
- **DropdownMenuTrigger asChild** — renders an `InputGroupButton` as the trigger.
- **DropdownMenuRadioGroup** — one active item per group.
- **InputGroupButton type="submit"** — the send action, disabled when the textarea is empty.

## Grouped models

Show each provider as a `DropdownMenuGroup` with a `DropdownMenuLabel` heading. The separator between groups comes from `DropdownMenuSeparator`:

```tsx
<DropdownMenuRadioGroup onValueChange={setModel} value={model}>
  {providers.map((provider, index) => (
    <React.Fragment key={provider.name}>
      {index > 0 && <DropdownMenuSeparator />}
      <DropdownMenuGroup>
        <DropdownMenuLabel>{provider.name}</DropdownMenuLabel>
        {provider.models.map((item) => (
          <DropdownMenuRadioItem key={item.id} value={item.id}>
            {item.name}
          </DropdownMenuRadioItem>
        ))}
      </DropdownMenuGroup>
    </React.Fragment>
  ))}
</DropdownMenuRadioGroup>
```

## Best Practices

- **Always show the current model.** The trigger label is the value, so users see it without opening the menu.
- **Group by provider.** Models across providers differ in capability and cost; the group heading tells the user which family they are picking.
- **Disable Send when empty.** `disabled={!canSend}` prevents accidental empty submissions.
- **Attach is not Send.** Use a separate icon-only button with `type="button"` for attachments so Enter doesn't submit the file picker.
- **Effort is a second dropdown.** Do not fold effort into the model name; users change it independently.

## Accessibility

- Both `DropdownMenuTrigger` instances use `asChild` so the trigger is a real `InputGroupButton` (a button element) with an `aria-label` describing its value.
- `DropdownMenuRadioGroup` exposes `role="radiogroup"` per group and `role="menuitemradio"` per item; arrow keys move the selection.
- The Send button has `aria-label="Send"` and is disabled when the composer is empty.
- The attach button has `aria-label="Attach"` and is `type="button"` so it never submits the form.
