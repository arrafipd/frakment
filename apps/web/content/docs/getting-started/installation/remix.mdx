Frakment works in any Remix 2+ project with React 19 and Tailwind v4. This guide covers both a new project via the CLI and an existing app.

## Prerequisites

- **Remix** 2 or newer
- **React** 19
- **TypeScript**
- **Tailwind CSS** v4

Components target React 19 and Tailwind v4. For React 18, some components need `forwardRef` adjustments. For Tailwind v3, port the tokens from [Theming](/docs/guides/theming) manually.

## Use the CLI

Scaffold a new Remix app with Frakment installed.

<Steps>

<Step>Create project</Step>

```bash
npx create-remix@latest app
cd app
```

<Step>Install Tailwind v4</Step>

```bash
npm install tailwindcss@latest @tailwindcss/vite
```

Register the Vite plugin:

```ts title="vite.config.ts"
import { vitePlugin as remix } from "@remix-run/dev";
import tailwindcss from "@tailwindcss/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [remix(), tailwindcss()],
});
```

<Step>Add components</Step>

```bash
npx frakment@latest init
npx frakment@latest add bubble
```

<Step>Use it</Step>

```tsx title="app/routes/_index.tsx"
import { Bubble, BubbleContent } from "@/components/ui/bubble";

export default function Index() {
  return (
    <Bubble>
      <BubbleContent>Hello, Frakment.</BubbleContent>
    </Bubble>
  );
}
```

</Steps>

## Existing Project

Add Frakment to a Remix app you already created.

<Steps>

<Step>Install Tailwind v4</Step>

```bash
npm install tailwindcss@latest @tailwindcss/vite
```

Register the Vite plugin:

```ts title="vite.config.ts"
import { vitePlugin as remix } from "@remix-run/dev";
import tailwindcss from "@tailwindcss/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [remix(), tailwindcss()],
});
```

<Step>Run frakment init</Step>

```bash
npx frakment@latest init
```

Point to `app/tailwind.css` when prompted. The CLI injects the theme block after your imports.

<Step>Configure the import alias</Step>

In `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

<Step>Add a component</Step>

```bash
npx frakment@latest add bubble
```

</Steps>

## Verify

```bash
ls app/components/ui/bubble.tsx
```

Then render it in a route. If it renders without errors, you are ready.

## Troubleshooting

<Accordion type="single" collapsible>

<AccordionItem value="vite-plugin">
<AccordionTrigger>Tailwind classes not applied</AccordionTrigger>
<AccordionContent>

Make sure `@tailwindcss/vite` is registered in `vite.config.ts` and restart the dev server. Vite caches the plugin list in memory.

</AccordionContent>
</AccordionItem>

<AccordionItem value="alias">
<AccordionTrigger>Cannot resolve @/components</AccordionTrigger>
<AccordionContent>

Check `tsconfig.json` `paths` and the `aliases` in `components.json`. Both must match.

</AccordionContent>
</AccordionItem>

</Accordion>
