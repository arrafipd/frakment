Frakment is a registry of editable React and React Native components that you add to your own project.

The web CLI installs web components, and its Expo mode installs the native components listed in the native catalog.

## Installation

### Web

Initialize Frakment in an existing React 19 and Tailwind CSS v4 project, then add a component:

```bash
npx frakment@latest init
npx frakment@latest add button
```

The CLI requires Node.js 22.18.0 or newer.

### Expo

Initialize Frakment in an existing Expo and NativeWind project, then add a native component:

```bash
npx frakment@latest init --expo
npx frakment@latest add button --expo
```

See the [native installation guide](/docs/getting-started/installation/native) for Expo requirements and setup details.

### Manual installation

Copy component source from its documentation page and follow the [manual setup guide](/docs/getting-started/installation/manual).

## Motion

Web components that expose a `motion` prop use CSS transitions and respect the reduced-motion preference.

Native components use immediate state changes and do not expose the web `motion` prop.

See the [animations guide](/docs/guides/animations) for supported web behavior.

## AI interface examples

AI Elements are UI compositions and examples, not model providers or backend services.

Connect the components to your own model, transport, and application logic.

## Agent tools

The [MCP server](/docs/utilities/mcp) exposes registry search, component source, compositions, and CLI install commands.

The MCP server returns commands for the agent to use and does not write files into your project.

Frakment also publishes an [LLM documentation index](/docs/resources/llms) and [agent skills](/docs/utilities/skills).
