Two library changes ship today. A new card with a procedural foil that reacts to pointer tilt and device motion, and a fix for the credit card that removes an internal import so it installs cleanly.

- [Holo Card](#holo-card): New module.
- [Credit Card](#credit-card): Fix internal brand dependency.

### Holo Card

<ComponentPreview name="holo-card" title="holo-card-demo.tsx" src="examples/holo-card-demo.tsx" previewClassName="h-auto py-8">
  <HoloCardDemo />
</ComponentPreview>

Two presets ship: `bursts` (default) and `cosmos`. Card mode accepts a `logo` (URL, text, or any ReactNode) and an optional `chip` override. Image mode (`variant="image"` or a `HoloCardImage` child) renders artwork under the foil.

#### Installation

<Steps>
  <Step>Install</Step>

```bash
npx frakment@latest add holo-card
```
</Steps>

#### Minimal usage

```tsx
<HoloCard logo="/logo.svg" preset="bursts" />
```

```tsx
<HoloCard variant="image" preset="cosmos">
  <HoloCardImage alt="Card" src="/card.avif" />
</HoloCard>
```

### Credit Card

<ComponentPreview name="credit-card" title="credit-card-demo.tsx" src="examples/credit-card-demo.tsx" previewClassName="h-auto py-8">

</ComponentPreview>

`CreditCardIssuer` no longer imports the site-internal `@/components/brand`. Pass a `logo` or `children` to render a mark; omitting both renders nothing. Fresh installs of `credit-card` no longer fail with a module-not-found error.

#### Installation

<Steps>
  <Step>Update</Step>

```bash
npx frakment@latest add credit-card
```
</Steps>

#### Minimal usage

```tsx
<CreditCard>

  </CreditCardHeader>

    <CreditCardHolder value="John Doe" />
    <CreditCardExpiry value="1228" />
  </CreditCardFooter>
</CreditCard>
```

### Button

<ComponentPreview name="button-anchor" title="button-anchor.tsx" src="examples/button-anchor.tsx">
  <ButtonAnchor />
</ComponentPreview>

Pass `href` to render the button as a native anchor. `<Button href="/docs">Read the docs</Button>` produces a link without a wrapper. For client-side navigation with Next.js, React Router, or TanStack Router, apply the button styles with `buttonVariants` and render the router link component. The `asChild` prop is removed from the published registry file. The `button` entry no longer depends on `radix-ui`, so `npx frakment add button` installs only `class-variance-authority`. Migrate existing usages by replacing `<Button asChild><a href="/x">Text</a></Button>` with `<Button href="/x">Text</Button>`. Use `anchorRef` to access the underlying anchor element; `ref` targets the `<button>` element only. A new `motion` prop overrides the default Tailwind transition. Pass `"off"` to disable, or a value like `"slow easeOut"` or `"150 cubic-bezier(...)"`. `prefers-reduced-motion: reduce` overrides every value. Components that drive animation with GSAP, Framer Motion, or the Web Animations API do not need any extra prop. The component detects the external inline style write and disables its own transition.

#### Installation

```bash
npx frakment@latest add button
```
</Steps>

