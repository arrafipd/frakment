Removed `animation.ts` and `animation-curves.ts` from `lib/`. All animation now uses the `motion` prop via `lib/motion.ts` (`parseMotion`, `getTransition`, `useReducedMotion`, `useMotionGuard`).

Removed `credit-card` and `holo-card` from the registry. `npx frakment add credit-card` and `npx frakment add holo-card` return 404. Existing installs continue to work.

Rewrote `content/docs/guides/animations/index.mdx` to document the `motion` prop instead of the removed `animation` DSL. Removed cubic-bezier curve grid and custom curve components from the docs page.

Removed `text-morph` CSS from `styles/globals.css`. Removed `lib/message-animations.ts` — message animations now use inline Motion variants instead of imported animation config.
