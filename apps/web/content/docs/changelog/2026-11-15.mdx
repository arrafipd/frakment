**Label** now ships as a native `<label>` with no runtime dependency. The `radix-ui` package is no longer required to install it.

<hr className="my-16 border-border/40" />

### Label

<ComponentPreview name="label" title="label.tsx">
  <LabelDemo />
</ComponentPreview>

**Label** renders a native `<label>` that forwards clicks to its associated control via `htmlFor`. Behavior is unchanged for consumers using `htmlFor` and `className`. The mousedown guard that prevents double-click text selection is preserved. The `as` prop is intentionally not added: a polymorphic label would lose the `htmlFor` association.

#### Installation

```bash
npx frakment@latest add label
```

### Message consolidation

**Message**, **Bubble**, **MessageScroller**, and **MessageAnimated** now ship as a single registry component. `npx frakment add message` installs all four primitives: layout (`Message`, `MessageGroup`, `MessageContent`), bubble (`Bubble`, `BubbleContent`, `BubbleReactions`), scroll behavior (`MessageScroller*` + three hooks), and animated message (`MessageAnimated`).

The scroll engine is inlined. The `@frakment/react` package is no longer published. Imports from `@frakment/react/message-scroller` must migrate to `@/components/ui/message` after running `npx frakment@latest add message`.

No runtime dependencies beyond `class-variance-authority` and `lucide-react`. The `radix-ui` and `ai` dependencies are removed from the bubble and animated parts.

**Migration from the old registry names**

- `npx frakment add bubble` → `npx frakment add message`
- `npx frakment add message-scroller` → `npx frakment add message`
- `npx frakment add message-animated` → `npx frakment add message`
- `import ... from "@/components/ui/bubble"` → `import ... from "@/components/ui/message"`

The `BubbleContent` `asChild` prop is replaced by `as`. Pass `as={Link}` or `as="a" for clickable bubbles.

#### Installation

```bash
npx frakment@latest add message
```

#### Minimal usage

```tsx
<MessageScrollerProvider>
  <MessageScroller>
    <MessageScrollerViewport>
      <MessageScrollerContent>
        <MessageAnimated message={message} scrollAnchor={message.role === "user"} />
      </MessageScrollerContent>
    </MessageScrollerViewport>
    <MessageScrollerButton />
  </MessageScroller>
</MessageScrollerProvider>
```

### Marker, Attachment, Switch, Progress

Four more components drop `radix-ui` and ship as native primitives. **Marker** and **Attachment** replace the `asChild` prop with `as` for polymorphic rendering. **Switch** and **Progress** expose a `motion` prop so you can override the CSS transition without editing the file.

All four now render with `role=switch` / `role=progressbar` / native `<div>` + `aria-*` attributes directly, so the shipped file has no external primitive dependency. `prefers-reduced-motion` disables transitions automatically, and third-party animation libraries that write inline styles suppress the internal transition via `useMotionGuard`.

```bash
npx frakment@latest add marker attachment switch progress
```

#### Motion prop

```tsx
<Switch motion="300 cubic-bezier(0.34, 1.56, 0.64, 1)" />
<Progress motion="500 ease-out" value={60} />
```

#### `as` prop (R16)

```tsx
<Marker as="a" href="/branch">View branch</Marker>
<Attachment>
  <AttachmentTrigger as="a" href="/report.pdf" aria-label="Open report" />
</Attachment>
```

`asChild` on `AttachmentTrigger` is no longer supported. Migrate to `as`:

```diff
- <AttachmentTrigger asChild><a href="..." /></AttachmentTrigger>
+ <AttachmentTrigger as="a" href="..." />
```

### Slider, Tooltip

The last two Radix primitives drop to native implementations. **Slider** renders `<div role="slider">` per thumb with pointer and keyboard handling in a single file. **Tooltip** renders `<div role="tooltip">` with floating-ui positioning, hover/focus trigger, and portal. `radix-ui` is no longer a runtime dependency for either.

`TooltipTrigger` replaces the Radix `asChild` pattern with an `as` prop (R16). `asChild` stays for backward compat (deprecated) but `as={Button}` is the recommended call.

```bash
npx frakment@latest add slider tooltip
```

#### Tooltip `as` prop

```tsx
<Tooltip>
  <TooltipTrigger as={Button} variant="outline">Hover</TooltipTrigger>
  <TooltipContent>Add to library</TooltipContent>
</Tooltip>
```

#### Slider keyboard support

Arrow keys step, Home/End jump, Page Up/Down step × 10. Multi-thumb sliders respect thumb ordering automatically.

`motion` prop on TooltipContent overrides the entrance transition. Slider keeps its color/box-shadow hover transition and does not expose a motion prop (no positioning animation to tune).
