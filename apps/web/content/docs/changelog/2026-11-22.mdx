The CLI and MCP packages now ship compiled JavaScript entry points so Node.js can run them without stripping TypeScript from dependencies.

The CLI's shipped `components.json` template now uses the canonical Frakment registry URL instead of the legacy Vercel alias.

Updated older changelog links to current documentation routes and removed the obsolete `lib/animation.ts` helper from CLI initialization and the installation guide.
