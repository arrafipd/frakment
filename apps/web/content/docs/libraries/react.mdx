The `@frakment/react` package is no longer published. Its `message-scroller` engine now ships inside the `message` registry component.

## Migration

Install the `message` component:

```bash
npx frakment@latest add message
```

Replace the package import with the component import:

```tsx
import { MessageScroller } from "@/components/ui/message";
```

The `MessageScroller` export shape is unchanged. The compound has the same six parts (`Provider`, `Root`, `Viewport`, `Content`, `Item`, `Button`) and the three hooks (`useMessageScroller`, `useMessageScrollerScrollable`, `useMessageScrollerVisibility`) remain available.

## Why

Scroll behavior and bubble rendering belong together. Consolidating into a single file removes the React 19 peer requirement at the docs level, drops the npm dependency, and lets the copy-paste workflow own the entire chat UI.

See [Message](/docs/components/web/message) for the full component.
