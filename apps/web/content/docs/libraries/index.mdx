Frakment provides a CLI for installing registry components and initializing project themes.

## Layers

| Layer            | Import                    | Purpose                    | Status |
| ---------------- | ------------------------- | -------------------------- | ------ |
| **frakment CLI** | `npx frakment@latest ...` | Install components + theme | Stable |

## Design principles

- **Source ownership.** Installed components become part of your project and can be edited directly.
- **Registry-first.** The CLI resolves component dependencies and installs the required npm packages.

## Distribution

| Layer                            | Installed via                    |
| -------------------------------- | -------------------------------- |
| Components (`button`, `card`, …) | `npx frakment@latest add <name>` |
| Theme (tokens + utilities)       | `npx frakment@latest init`       |
