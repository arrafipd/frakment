---
title: React 19
description: React requirements for Frakment components.
---

Frakment web components require React 19 and React DOM 19.

React 18 is not a supported target, even when an individual component appears to work.

## Peer dependencies

Keep `react` and `react-dom` on compatible React 19 versions in your application:

```json title="package.json"
{
  "dependencies": {
    "react": "^19.0.0",
    "react-dom": "^19.0.0"
  }
}
```

The Frakment CLI requires Node.js 22.18.0 or newer.
