Frakment is a component registry for React interfaces.

It distributes editable component source that you add to and maintain in your own project.

## Principles

### Monochrome by default

The default theme uses a neutral palette with semantic tokens for surfaces, text, borders, and status.

Override the tokens to match your product, as described in [Theming](/docs/guides/theming).

### Components and compositions

Components are installed individually with the CLI.

Compositions such as chat and agent interfaces combine registry components and are documented as examples.

```bash
npx frakment add message input-group trace code-block
```

### Editable source

The CLI copies component source into your project so you can inspect and change it.

AI interface examples provide UI only; connect them to your own model, transport, and application logic.

### Motion

Web components that expose a `motion` prop use CSS transitions.

Native components currently use immediate state changes.

## Comparison

| Aspect | Frakment | Component library |
| :-- | :-- | :-- |
| Distribution | Source copied into your project | Installed as a dependency |
| Updates | Re-run the CLI when you choose | Update the package |
| Theme | Neutral defaults with editable tokens | Depends on the library |
| Ownership | Edit the copied source | Use the package API |

## Frequently asked

### Is Frakment Tailwind only?

Yes, Frakment web components require Tailwind CSS v4.

### Can I customize the colors?

Yes, override the theme tokens in your project.

### What about TypeScript?

Frakment component source is TypeScript.

For JavaScript projects, remove the type annotations after copying the source.
