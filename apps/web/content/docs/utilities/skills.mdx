A skill is a Markdown document that gives an AI agent focused instructions for a task.

Frakment publishes skills for understanding the site and using its component registry.

The skill content is provider-neutral and can be loaded by any assistant that can read Markdown.

Automatic discovery and tool access depend on each AI client.

The skill does not grant network, terminal, or project-write permissions.

Use the MCP server in clients that support MCP over stdio; otherwise follow the HTTPS and CLI instructions directly.

## Available skills

| Skill | Purpose |
| :-- | :-- |
| `frakment` | Introduces the Frakment site and its resources. |
| `frakment-usage` | Provider-neutral HTTP, MCP, and CLI workflows for web and Expo components. |

## Discover skills

Fetch the skill index to see the available instructions and their URLs:

```bash
curl https://www.arrafi.dev/frakment/.well-known/agent-skills/index.json
```

The site skill is available at `https://www.arrafi.dev/frakment/.well-known/agent-skills/site-skill.md`.

The registry usage skill is available at `https://www.arrafi.dev/frakment/skills/frakment-usage/SKILL.md`.

Load the Markdown content into the agent context when the task matches the skill description.

Use `/r/index.json` to discover web components and `/r/expo/index.json` to discover Expo components.

For registry access without MCP, use the HTTPS endpoints and CLI commands in the skill.
