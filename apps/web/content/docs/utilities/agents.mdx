Frakment provides an MCP server and an agent skill for discovering components, composing scenarios, and retrieving CLI commands.

## The workflow

<Steps>
  <Step>Agent calls `compose` with a scenario name</Step>

  MCP returns a curated component list, an install command, and dependency notes.

  <Step>Agent can call `get_install_command` for an individual component</Step>

  MCP returns the `npx` command; the CLI resolves that component's `registryDependencies`.

  <Step>User or authorized agent runs the command in the target project</Step>

  The CLI writes the components and resolves their dependencies.
</Steps>

## Chat UI

**Prompt:** "Build a chat interface with auto-scroll"

The agent calls `compose`:

```json
{
  "tool": "compose",
  "arguments": { "scenario": "chat" }
}
```

MCP responds:

```text
# chat
Chat interface with auto-scroll and animated turns

Components: message, avatar

Install: npx frakment@latest add message

message includes the message, bubble, scroll, and animated message primitives. Add avatar separately.
```

The agent calls `get_install_command`:

```json
{
  "tool": "get_install_command",
  "arguments": { "name": "message" }
}
```

MCP responds:

```bash
npx frakment@latest add message
```

`message` includes the message, bubble, scroll, and animated message primitives. Add `avatar` separately if needed.

## Agent timeline

**Prompt:** "Build an agent activity timeline with code output"

The agent calls `compose`:

```json
{
  "tool": "compose",
  "arguments": { "scenario": "agent-timeline" }
}
```

MCP responds:

```text
# agent-timeline
Agent activity view with trace steps and code output

Components: trace, code-block

Install: npx frakment@latest add trace code-block

trace pulls collapsible and shimmer; code-block pulls button.
```

The agent calls `get_install_command`:

```json
{
  "tool": "get_install_command",
  "arguments": { "name": "trace" }
}
```

MCP responds:

```bash
npx frakment@latest add trace
```

`trace` pulls `collapsible` and `shimmer`. `compose` includes all requested components in its install command.

## Login form

**Prompt:** "Build an accessible login form"

The agent calls `compose`:

```json
{
  "tool": "compose",
  "arguments": { "scenario": "login-form" }
}
```

MCP responds:

```text
# login-form
Accessible login form with remember-me toggle

Components: field, label, input, button, checkbox

Install: npx frakment@latest add field input button checkbox

field pulls label and separator; the CLI resolves registry dependencies for all components.
```

The agent calls `get_install_command`:

```json
{
  "tool": "get_install_command",
  "arguments": { "name": "field" }
}
```

MCP responds:

```bash
npx frakment@latest add field
```

`field` pulls `label` and `separator`.

## All scenarios

| Scenario | What you get | Entry |
| :--- | :--- | :--- |
| `chat` | Chat UI with auto-scroll, avatar, and animated turns | `message` |
| `agent-timeline` | Activity view with trace steps and code output | `trace`, `code-block` |
| `code-output` | Syntax-highlighted code with copy actions and line diffs | `code-block` |
| `empty-state` | Zero-data placeholder with optional call-to-action | `empty`, `button` |
| `login-form` | Accessible form with field, label, input, button, and checkbox | `field`, `input`, `button`, `checkbox` |
| `search-input` | Search field with inline button and loading state | `input-group`, `spinner` |
| `settings-panel` | Settings view with boolean toggles and grouped options | `field`, `switch`, `toggle-group`, `separator` |

Call `list_scenarios` with no input to get the current set. The tool is the source of truth so the list stays current.
