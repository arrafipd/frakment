Scroll fade adds a mask-image gradient to the edges of a scroll container so content dissolves into the background when there is more content beyond the visible area.

## Usage

| Class | Styles |
| :-- | :-- |
| `scroll-fade` | Fade on both vertical edges, scroll-aware. |
| `scroll-fade-x` | Fade on both horizontal edges, scroll-aware. |
| `scroll-fade-t` | Fade on the top edge only. |
| `scroll-fade-b` | Fade on the bottom edge only. |
| `scroll-fade-l` | Fade on the left edge only. |
| `scroll-fade-r` | Fade on the right edge only. |
| `scroll-fade-s` | Fade on the logical start edge. |
| `scroll-fade-e` | Fade on the logical end edge. |
| `scroll-fade-none` | Remove the fade. |
