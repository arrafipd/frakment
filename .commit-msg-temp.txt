refactor(message)!: consolidate message, bubble, message-scroller, message-animated into one component

One CLI command installs the whole chat UI: layout primitives, bubble with
seven variants, scroll engine with three hooks, and the animated message
renderer. `npx frakment add message` covers every case the four previous
components handled separately.

The @frakment/react package is deleted. Its message-scroller engine is
inlined into the registry message file, so the copy-paste workflow owns the
entire scroll behavior. `radix-ui` and `ai` are no longer runtime deps of
the consolidated component; scroll behavior stays self-contained and the
animated part uses CSS transitions with prefers-reduced-motion respected.

Breaking:
- `bubble`, `message-scroller`, `message-animated` registry entries removed
- `@frakment/react` package removed
- `BubbleContent` asChild prop replaced by `as` (R16 pattern)
- `MessageAnimated` animation is now CSS-based; third-party libraries
  (GSAP, WAAPI) attach cleanly via useMotionGuard

Migration for existing consumers:
  npx frakment@latest add message
  Replace `@/components/ui/bubble`, `@/components/ui/message-scroller`,
  and `@/components/ui/message-animated` imports with
  `@/components/ui/message`.
  Replace `@frakment/react/message-scroller` with the same path.

Also updates: libraries/react (deprecation stub), libraries/index
(entry removed), advanced/javascript, advanced/react-19, resources/about,
resources/faq, next.config transpilePackages, audit scripts, CLI test mock,
SECURITY.md, THIRD_PARTY_NOTICES.md.

ComponentPreview previewClassName added to all four demos so tall content
no longer clips against the default h-72. The two demos that used
`@ai-sdk/react` now stream with plain `setTimeout` so the docs remain
self-contained.

Changeset: .changeset/message-consolidation.md (frakment major,
@frakment/react major).
