# Attribution

If you use Frakment in your project, we appreciate a credit line in your README or footer:

> Based on [Frakment](https://github.com/frakment/ui).

This is a courtesy, not a legal requirement for Frakment-authored code.

The MIT license requires that you keep its copyright notice and license text
when you redistribute that source code.

Third-party code may have separate notice or attribution requirements; see
[third-party notices](./legal/THIRD_PARTY_NOTICES.md) and the upstream licenses.

## What counts as clear attribution

- **Good**: a README line, a footer link, or an "About" section that names
  Frakment and links to the repo.
- **Nice to have, but not required**: a source code comment.

If you are unsure, open an issue and ask.

## Questions

Open an issue at [github.com/frakment/ui/issues](https://github.com/frakment/ui/issues).
