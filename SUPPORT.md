# Support

## Where to get help

| Need | Where |
| :-- | :-- |
| Bug in a component, CLI, or package | [Open an issue](https://github.com/arrafipd/frakment/issues/new/choose) using the **Bug report** template |
| Question, idea, or usage help | [GitHub Discussions](https://github.com/arrafipd/frakment/discussions) |
| Security vulnerability | [GitHub Security Advisories](https://github.com/arrafipd/frakment/security/advisories/new) — see [SECURITY.md](./SECURITY.md) |
| Code of Conduct concern | [GitHub Security Advisories](https://github.com/arrafipd/frakment/security/advisories/new) with `[conduct]` in the title — see [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) |
| Documentation | [https://www.arrafi.dev/frakment/docs](https://www.arrafi.dev/frakment/docs) |

## Before opening an issue

1. Search [existing issues](https://github.com/arrafipd/frakment/issues) and [discussions](https://github.com/arrafipd/frakment/discussions).
2. Upgrade to the latest version: `npx frakment@latest add <name>` rewrites the file with the current release.
3. Reduce to a minimal reproduction — one component plus the props that trigger the bug.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for the full workflow.
