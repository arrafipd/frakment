### Attachment

<ComponentPreview name="attachment" title="attachment.tsx" previewClassName="h-auto py-8">
  <AttachmentDemo />
</ComponentPreview>

**Attachment** renders a compact file card with media, title, description, and actions. It supports idle, uploading, processing, error, and done states with size variants for dense layouts. Pass `variant="image"` to render a thumbnail, or wrap with `AttachmentTrigger` to make the whole card interactive.

#### Installation

<Steps>
  <Step>Install the primitive</Step>

```bash
npx frakment add attachment
```

<Step>Use it in your app</Step>

```tsx
import {
  Attachment,
  AttachmentContent,
  AttachmentDescription,
  AttachmentMedia,
  AttachmentTitle,
} from "@/components/ui/attachment";
```

</Steps>

#### Minimal usage

```tsx
<Attachment>
  <AttachmentMedia>
    <FileTextIcon />
  </AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>report.pdf</AttachmentTitle>
    <AttachmentDescription>PDF · 2.4 MB</AttachmentDescription>
  </AttachmentContent>
</Attachment>
```

See the [Attachment docs](/docs/components/attachment) for the full API reference.

### Scroll fade

<ComponentPreview name="scroll-fade-overflow" title="scroll-fade-overflow.tsx">
  <ScrollFadeOverflow />
</ComponentPreview>

**scroll-fade** applies a scroll-aware mask to the edges of a scroll container. The fade tracks the scroll position, only appearing when there is content beyond the visible area. Variants: `scroll-fade-x` for horizontal, `scroll-fade-{t,b,l,r,s,e}` for single edges, and `scroll-fade-none` to disable.

#### Installation

```bash
npx frakment add scroll-fade
```

#### Minimal usage

```tsx
<div className="scroll-fade overflow-y-auto">{/* ... */}</div>
```

See the [Scroll Fade docs](/docs/utilities/scroll-fade) for the full reference.


### Hover Card

<ComponentPreview name="hover-card" title="hover-card-demo.tsx">
  <HoverCardDemo />
</ComponentPreview>

**Hover Card** displays rich content in a portal when the user hovers over a trigger. It opens after a short delay, stays open while the pointer is over the card, and closes on mouse leave. Built on Radix `HoverCard`, it supports `side`, `align`, `openDelay`, and `closeDelay`.

#### Installation

<Steps>
  <Step>Install the primitive</Step>

```bash
npx frakment add hover-card
```

<Step>Use it in your app</Step>

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card";
```

</Steps>

#### Minimal usage

```tsx
<HoverCard>
  <HoverCardTrigger asChild>
    <Button variant="link">@fraktment</Button>
  </HoverCardTrigger>
  <HoverCardContent>
    Registry primitives for React.
  </HoverCardContent>
</HoverCard>
```

See the [Hover Card docs](/docs/components/hover-card) for the full API reference.

### Questionnaire

<ComponentPreview name="questionnaire" title="questionnaire-demo.tsx">
  <QuestionnaireDemo />
</ComponentPreview>

**Questionnaire** is a multi-step form **component** that bundles a headless engine. Each step renders one question with a title, optional description, a set of choices, optional freeform input, and inline error. Navigation between steps and the final submit are handled by the headless engine in `lib/questionnaire`, which ships as a registry dependency.

#### Installation

<Steps>
  <Step>Install the primitive (pulls the engine automatically)</Step>

```bash
npx frakment add questionnaire checkbox radio-group button card
```

<Step>Use it in your app</Step>

```tsx
import {
  Questionnaire,
  QuestionnaireActions,
  QuestionnaireChoice,
  QuestionnaireChoices,
  QuestionnaireItem,
  QuestionnaireNext,
  QuestionnairePrevious,
  QuestionnaireSubmit,
  QuestionnaireTitle,
} from "@/components/ui/questionnaire";
```

</Steps>

#### Minimal usage

```tsx
<Questionnaire items={items} onSubmit={handleSubmit}>
  <QuestionnaireItem name="scope" required>
    <QuestionnaireTitle>What should the agent change?</QuestionnaireTitle>
    <QuestionnaireChoices>
      <QuestionnaireChoice value="component">Component only</QuestionnaireChoice>
      <QuestionnaireChoice value="feature">Complete feature</QuestionnaireChoice>
    </QuestionnaireChoices>
  </QuestionnaireItem>
  <QuestionnaireActions>
    <QuestionnairePrevious />
    <QuestionnaireNext>Next</QuestionnaireNext>
    <QuestionnaireSubmit>Save</QuestionnaireSubmit>
  </QuestionnaireActions>
</Questionnaire>
```

See the [Questionnaire docs](/docs/modules/questionnaire) for the full API reference.

