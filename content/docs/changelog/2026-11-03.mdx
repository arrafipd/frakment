This release adds eleven form primitives, an icon shim component, and a first-party AI engine replacing the external helper.

- [Form primitives](#form-primitives): 11 new inputs, controls, and layout primitives.
- [Icon shim](#icon-shim): `lib/icons.ts` re-exports Phosphor under Lucide-compatible names.
- [Changed](#changed): Message-scroller polish — rounded-full buttons, `ChatCircleDots` empty icon.
- [First-party AI engine](#first-party-ai-engine): `@/lib/ai` replaces the external helper 1:1.

### Form primitives

Eleven new primitives, all built on Radix UI. Compose with `Field` for labels, descriptions, and error states.


### Icon shim

`lib/icons.ts` is now a first-class registry component (`npx frakment add icons`). It re-exports Phosphor icons under Lucide-compatible names (`Check as CheckIcon`, `TextB as BoldIcon`, …) so components can swap icon libraries with a single import change.

Every Frakment component that imports `@/lib/icons` now declares `icons` as a `registryDependency`, so `npx frakment add <component>` installs the shim automatically.

<hr className="my-16 border-border/40" />

### Changed

- **Message Scroller** — scroll-to-end button is now `rounded-full`, empty state uses `ChatCircleDots`, and the viewport opts into the shared scrollbar theme. No API change.

<hr className="my-16 border-border/40" />

### First-party AI engine

`@/lib/ai` is now a full 1:1 behavioral port of the external helper library. Same `createChat()` API, same `ChatTransport` contract, same chunk encoding, same continuation semantics, same tools/approvals/files/sources support.

No consumer code changes — `import { createChat, getMessageText } from "@/lib/ai"` still works, and `lib/ai/` is bundled with any component that depends on it. Publishing as `@frakment/ai` is planned.

See the [AI Helpers reference](/docs/libraries/ai) for the full API.
