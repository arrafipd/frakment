This release adds **thirteen registry components** and expands **Text Flip** with ten transition variants.

- [Accordion](#accordion): Collapsible sections with single or multiple expansion.
- [Card](#card): Now installable via `npx frakment add card`.
- [Collapsible](#collapsible): Single-panel expand and collapse with animated height.
- [Dropdown Menu](#dropdown-menu): Menu with items, checkboxes, submenus, and three alignment values.
- [Tabs](#tabs): Layered content panels with vertical and disabled support.
- [Text Flip](#text-flip): Ten variants for animating text and numbers.
- [Tooltip](#tooltip): Hover and focus popup with three side placements.
- [Breadcrumb](#breadcrumb): Path hierarchy with dropdown and ellipsis.
- [Button Group](#button-group): Merged clusters of buttons, inputs, and selects.
- [Input OTP](#input-otp): One-time password input with pattern and length control.
- [Pagination](#pagination): Page navigation with numbered and icon-only variants.
- [Radio Group](#radio-group): Mutually exclusive options with fieldset support.
- [Toast](#toast): Sonner-based notifications with types and promises.

### Accordion

<ComponentPreview name="accordion" title="accordion.tsx">
  <AccordionDemo />
</ComponentPreview>

**Accordion** stacks headings that each reveal a section of content. It supports `type="single"` and `type="multiple"`, item-level `disabled`, and animated height transitions. Trigger and content use `data-slot` markers for styling hooks.

#### Installation

<Steps>
  <Step>Install the primitive</Step>

~~~bash
npx frakment add accordion
~~~

<Step>Use it in your app</Step>

~~~tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
~~~

</Steps>

#### Minimal usage

~~~tsx
<Accordion collapsible defaultValue="item-1" type="single">
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA design pattern.
    </AccordionContent>
  </AccordionItem>
</Accordion>
~~~

See the [Accordion docs](/docs/components/accordion) for the full API reference.

### Text Flip

<ComponentPreview name="text-flip" title="text-flip.tsx">
  <TextFlipRoll />
</ComponentPreview>

**Text Flip** ships with ten variants: `flip`, `fade`, `blur`, `slide`, `scale`, `count`, `roll`, `shuffle`, `typewriter`, and `wave`. Numeric variants (`count`, `roll`) interpolate numbers via `@number-flow/react`. The `as` prop chooses the rendered element. `typewriter` and `wave` accept a `speed` prop in milliseconds.

#### Installation

<Steps>
  <Step>Install</Step>

~~~bash
npx frakment add text-flip
~~~

<Step>Use it in your app</Step>

~~~tsx
import { TextFlip } from "@/components/ui/text-flip";
~~~

</Steps>

#### Minimal usage

~~~tsx
<TextFlip>{"Build", "Ship", "Iterate"}</TextFlip>
~~~

See the [Text Flip docs](/docs/components/text-flip) for the full API reference.

### Changed: Icons use lucide-react

Components installed via `npx frakment add` now import from `lucide-react` instead of a bundled Phosphor shim. Running any `npx frakment add <component>` installs `lucide-react` automatically and no longer pulls `icons`.

~~~bash
npx frakment add button
# installs: class-variance-authority radix-ui lucide-react
~~~

The `icons` registry entry is removed. Projects that previously installed it can keep using it, but new installs should import from `lucide-react` directly.
