This release adds seven AI element tutorials — **Plan** and **Prompt Input** — plus a monochrome token pass that fixes disabled states across buttons, input groups, OTP inputs, and native selects.

- [Plan](#plan): Stream an agent plan with step status.
- [Prompt Input](#prompt-input): Composer with attachments, model, and effort pickers.
- [Queue](#queue): Grouped todo list with pending and completed sections.
- [Reasoning](#reasoning): Streaming thinking block with collapsible trace.
- [Sources](#sources): Collapsible list of agent source citations.
- [Stack Trace](#stack-trace): Failed command with parsed stack frames.
- [Subagent](#subagent): Live trace of a delegated task with nested tool calls.
- [Disabled state](#disabled-state): Muted background replaces reduced opacity.
- [Tokens](#tokens): `--subtle-foreground` and higher contrast for `--input` and `--border`.

### Plan

<ComponentPreview name="plan-demo" title="plan-demo.tsx" src="examples/plan-demo.tsx" previewClassName="h-auto py-8">
  <PlanDemo />
</ComponentPreview>

**Plan** renders an agent plan as a collapsible list of steps. Each step is `done`, `running`, or `pending`. The header shows progress and the whole block collapses. It is a composition over [Trace](/docs/components/trace).

#### Installation

<Steps>
  <Step>Install the primitives</Step>

```bash
npx frakment add trace message bubble button
```

<Step>Use it in your app</Step>

```tsx
import {
  Trace,
  TraceCollapsible,
  TraceCollapsibleContent,
  TraceCollapsibleTrigger,
  TraceDescription,
  TraceIcon,
  TraceLine,
  TraceTitle,
} from "@/components/ui/trace";
```

</Steps>

#### Minimal usage

```tsx
<Trace>
  <TraceCollapsible defaultOpen>
    <TraceCollapsibleTrigger>
      <TraceLine status="running">
        <TraceIcon><RouteIcon /></TraceIcon>
        <TraceTitle>{"Plan: migrate to Base UI"}</TraceTitle>
        <TraceDescription>{"1 of 4 done"}</TraceDescription>
      </TraceLine>
    </TraceCollapsibleTrigger>
    <TraceCollapsibleContent>
      <Trace>{/* steps */}</Trace>
    </TraceCollapsibleContent>
  </TraceCollapsible>
</Trace>
```

See the [Plan docs](/docs/ai-elements/plan) for the full composition.

### Disabled state

Disabled buttons now use a solid muted background instead of reduced opacity. Icons and labels stay readable while the control reads as inactive.

`InputGroup`, `InputOTP`, and `NativeSelect` no longer fade their entire container when a single child is disabled.

See the [Button docs](/docs/components/button) and [Input Group docs](/docs/components/input-group) for the updated variants.

<hr className="my-16 border-border/40" />

### Tokens

`--subtle-foreground` is available for interactive values inside muted surfaces, sitting between `--foreground` and `--muted-foreground`. `--input` and `--border` are lifted in both light and dark mode so form borders read against the surface. `--sidebar-primary` is monochrome in both modes. `<body>` now applies `bg-background` by default.

See the [Theming guide](/docs/theming) for the full token reference.
