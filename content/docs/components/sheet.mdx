## Usage

~~~tsx title="sheet.tsx"
import {
  Sheet, SheetClose, SheetContent, SheetDescription,
  SheetFooter, SheetHeader, SheetTitle, SheetTrigger,
} from "@/components/ui/sheet";
~~~

~~~tsx
<Sheet>
  <SheetTrigger asChild>
    <Button>Open</Button>
  </SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Title</SheetTitle>
      <SheetDescription>Description</SheetDescription>
    </SheetHeader>
    <SheetFooter>
      <SheetClose asChild>
        <Button variant="outline">Close</Button>
      </SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>
~~~
## Anatomy

- **Sheet** — root; accepts `open` / `onOpenChange`
- **SheetTrigger** — button; use `asChild`
- **SheetContent** — the panel; `side` = `top | right | bottom | left`, `showCloseButton` toggles the X
- **SheetHeader** / **SheetFooter** — layout slots
- **SheetTitle** / **SheetDescription** — required for accessibility
- **SheetClose** — dismiss button; use `asChild`

## Accessibility

- Focus is trapped inside the sheet while open.
- `SheetTitle` and `SheetDescription` are announced to screen readers.
- `Escape` closes the sheet unless prevented.
- Clicking the backdrop closes the sheet.

## Best Practices

- **Use for navigation, not for data entry.** Long forms belong on a page.
- **Keep the side consistent.** `right` for navigation, `bottom` for mobile menus.
- **Close on link click.** Otherwise the sheet sits between the user and the destination.
- **Do not stack sheets.** One at a time.
