Terminal pairs a command line with its collapsible output inside a trace row. It animates typed characters, tracks status, and reuses the trace primitives for layout.

## Anatomy

Terminal composes the trace layout with a code-block output panel.

- **Terminal** - root wrapper; delegates to Trace
- **TerminalCommand** - one command row with command text, status, and collapsible output

## Accessibility

- Status is conveyed through both an icon and color.
- The collapsible trigger exposes `aria-expanded`.
- Skips the typewriter when `prefers-reduced-motion` is set.
