## Usage

~~~tsx title="sonner.tsx"
import { Toaster } from "@/components/ui/sonner";
import { toast } from "sonner";
~~~

~~~tsx title="app/layout.tsx"
<Toaster position="top-center" />
~~~

~~~tsx
<Button onClick={() => toast("Event created")}>Show toast</Button>
~~~

## Types

Sonner ships five message types. Each picks an icon from the theme automatically.

<ComponentPreview name="sonner" title="sonner.tsx" previewClassName="h-auto py-16">
  <ToastTypes />
</ComponentPreview>

~~~tsx
toast.success("Saved");
toast.error("Failed");
toast.info("Heads up");
toast.warning("Careful");
~~~

## Promise

`toast.promise` switches the message as a promise resolves or rejects.

<ComponentPreview name="sonner" title="sonner.tsx" previewClassName="h-auto py-16">
  <ToastPromise />
</ComponentPreview>

~~~tsx
toast.promise(createEvent(), {
  loading: "Creating event…",
  success: (d) => \`\${d.name} created\`,
  error: "Could not create",
});
~~~

## Custom position

Default position is responsive: `top-center` on mobile and `bottom-right` on desktop. Override per toast with `position`, or set a fixed position on `<Toaster position="..." />` to disable responsive behavior.

<ComponentPreview name="sonner" title="sonner.tsx" previewClassName="h-auto py-16">
  <ToastPosition />
</ComponentPreview>

~~~tsx
toast("Saved", { position: "top-left" })
~~~

## Accessibility

- Each toast is announced via `aria-live="polite"`.
- Errors use `aria-live="assertive"` automatically.
- Dismiss with `toast.dismiss()` or the close button when enabled.
