Hover Card shows rich content when the user hovers over a trigger. It opens after a short delay, stays open while the pointer is over the card, and closes on mouse leave. Hovering also works on keyboard focus.

## Usage

```tsx title="hover-card.tsx"
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card";

<HoverCard>
  <HoverCardTrigger asChild>
    <Button variant="link">Hover Here</Button>
  </HoverCardTrigger>
  <HoverCardContent>
    Rich content goes here.
  </HoverCardContent>
</HoverCard>
```

## Delay

Pass `openDelay` and `closeDelay` to `HoverCard` to tune the timing. Defaults come from Radix (700ms open, 300ms close).

```tsx
<HoverCard openDelay={100} closeDelay={100}>
  <HoverCardTrigger asChild>
    <Button>Trigger</Button>
  </HoverCardTrigger>
  <HoverCardContent>...</HoverCardContent>
</HoverCard>
```

## API Reference

### HoverCard

Extends Radix `HoverCard.Root`.

<PropsTable
  rows={[
    { name: "open", type: "boolean", description: "Controlled open state." },

    { name: "onOpenChange", type: "(open: boolean) => void", description: "Fires when the card opens or closes." },

    { name: "closeDelay", type: "number", default: "300", description: "Milliseconds before closing." },
  ]}

### HoverCardTrigger

Extends Radix `HoverCard.Trigger`. Use `asChild` to compose with a Button, Link, or any focusable element.

### HoverCardContent

Extends Radix `HoverCard.Content`. Renders inside a portal.

## Accessibility

## Accessibility

- Hover Card is pointer-driven. Do not put interactive content inside it, use Dialog, Popover, or Dropdown Menu for that.
- Hover Card also opens on keyboard focus. Make sure the trigger is a focusable element such as `<button>` or `<a>`.
- Provide a visible text label on the trigger so keyboard and screen reader users understand what it does.

## Anatomy

```tsx title="hover-card.tsx"
<HoverCard>
  <HoverCardTrigger asChild>
    <Button>Trigger</Button>
  </HoverCardTrigger>
  <HoverCardContent>
    {/* rich content */}
  </HoverCardContent>
</HoverCard>
```

- **Root** — open state and timing
- **Trigger** — hoverable element; compose with `asChild`
- **Content** — portal-rendered card with slide and fade

## Best Practices

- **Keep content short.** Two or three lines.
- **Do not put interactive content inside.** Hover Card is pointer-driven.
- **Use for preview, not action.** Show metadata, not forms.
- **Add a visible trigger label.** Screen readers rely on trigger text.
