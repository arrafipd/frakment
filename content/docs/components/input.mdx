Input is a single-line text field for forms and inline editing. It inherits all native `<input>` attributes and behaviors, and pairs with [Field](/docs/components/field) for labels and descriptions.

### Invalid

Set `aria-invalid` on the input, or `data-invalid` on the **Field** wrapper, to trigger destructive styling.

<ComponentPreview name="input" title="input.tsx" previewClassName="h-auto py-8">
  <InputInvalid />
</ComponentPreview>

```tsx
<Field data-invalid>
  <FieldLabel htmlFor="email">Email</FieldLabel>
  <Input id="email" aria-invalid />
  <FieldDescription>This field contains validation errors.</FieldDescription>
</Field>
```

## API Reference

Extends `React.ComponentProps<"input">`. Every native attribute (`type`, `placeholder`, `value`, `onChange`, `disabled`, `required`, `aria-*`) is forwarded to the underlying `<input>`.

Adds `data-slot="input"` for styling hooks.
