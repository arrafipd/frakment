
## Examples

### Types

```tsx
<Input type="email" placeholder="Email" />
<Input type="password" placeholder="Password" />
<Input type="search" placeholder="Search" />
<Input type="file" />
```

### States

```tsx
<Input placeholder="Disabled" disabled />
<Input placeholder="Invalid" aria-invalid />
```

The `aria-invalid` attribute triggers the destructive ring color from the theme tokens.

## API Reference

Extends `React.ComponentProps<"input">`. Every native attribute (`type`, `placeholder`, `value`, `onChange`, `disabled`, `required`, `aria-*`) is forwarded to the underlying `<input>`.

Adds `data-slot="input"` for styling hooks.
