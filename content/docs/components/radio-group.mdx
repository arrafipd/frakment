Radio Group is a set of mutually exclusive options. Only one item can be selected at a time, and the group manages focus with arrow keys.

## Usage

~~~tsx title="radio-group.tsx"
import { Label } from "@/components/ui/label";
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group";
~~~

~~~tsx
<RadioGroup defaultValue="comfortable">
  <div className="flex items-center gap-3">
    <RadioGroupItem value="default" id="r1" />
    <Label htmlFor="r1">Default</Label>
  </div>
  <div className="flex items-center gap-3">
    <RadioGroupItem value="comfortable" id="r2" />
    <Label htmlFor="r2">Comfortable</Label>
  </div>
</RadioGroup>
~~~

## Anatomy

- **RadioGroup** - root wrapper; holds `value` or `defaultValue`
- **RadioGroupItem** - one checkable option; requires a unique `value` and matching `id`

Pair `RadioGroupItem` with `Field` for descriptions, fieldset semantics, and disabled or invalid state.

## Accessibility

- Built on Radix RadioGroup, following the WAI-ARIA radio group pattern.
- Arrow keys move the selection within the group.
- Each item must have a matching `Label` with `htmlFor`.
- Invalid state is conveyed via `aria-invalid` on the item and `data-invalid` on the wrapper.
