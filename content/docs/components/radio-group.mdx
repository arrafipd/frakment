Radio Group is a set of mutually exclusive options. Only one item can be selected at a time, and the group manages focus with arrow keys.

## Keyboard

| Key | Action |
| :-- | :-- |
| `Space` | Select the focused option |
| `↑` / `↓` | Move between options |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `radio-group`, `radio-group-item` |
| `data-state` | `checked` \| `unchecked` |
| `data-disabled` | `true` |
| `data-orientation` | `horizontal` \| `vertical` |

## Accessibility

- Built on Radix RadioGroup, following the WAI-ARIA radio group pattern.
- Arrow keys move the selection within the group.
- Each item must have a matching `Label` with `htmlFor`.
- Invalid state is conveyed via `aria-invalid` on the item and `data-invalid` on the wrapper.

## Best Practices

- **Use for exclusive choices.** Independent toggles belong in Checkbox.
- **Always set a default.** An empty radio group leaves the user unsure of the starting state.
- **Stack vertically for forms.** Horizontal layouts are hard to read past three options.
- **Pair with a visible label.** Every option needs a matching `Label htmlFor`.
