Tooltip is a Radix Tooltip primitive. It shows a small label on hover or focus, supports `side` / `align` / `sideOffset`, and requires wrapping the app in `TooltipProvider`.

## Usage

```tsx title="tooltip.tsx"
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip";
```

```tsx
<Tooltip>
  <TooltipTrigger asChild>
    <Button variant="outline">Hover</Button>
  </TooltipTrigger>
  <TooltipContent>
    <p>Add to library</p>
  </TooltipContent>
</Tooltip>
```

## Anatomy

```tsx
<Tooltip>
  <TooltipTrigger asChild />
  <TooltipContent />
</Tooltip>
```

- **Tooltip** — Radix `Tooltip.Root`; accepts `open`, `defaultOpen`, `onOpenChange`, `delayDuration`
- **TooltipTrigger** — the trigger; use `asChild` to merge into a single child
- **TooltipContent** — the popup; accepts `side`, `sideOffset`, `align`
- **TooltipProvider** — required ancestor (Frakment root layout already provides one)

Wrap a disabled button in a `<span>` — Radix needs a focusable/hoverable host to trigger the tooltip.

### TooltipContent

Extends Radix `Tooltip.Content`. Supports `side` (`top` / `right` / `bottom` / `left`), `sideOffset`, `align` (`start` / `center` / `end`), and `avoidCollisions`.

Adds `data-slot="tooltip-content"` for styling hooks.
