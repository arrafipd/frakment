Input Group wraps a single input or textarea and lets you compose inline addons — icons, text prefixes, and buttons — in a single bordered surface.

## Anatomy

```tsx
<InputGroup>
  <InputGroupAddon align="inline-start">
    <Search />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon align="inline-end">
    <InputGroupButton>Go</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```

- **InputGroup** — bordered wrapper; auto-sizes height when an addon uses `align="block-start"` / `align="block-end"`
- **InputGroupAddon** — icon, text, or button container; `align` controls position
- **InputGroupButton** — compact button sized for the group; inherits from Frakment `Button`
- **InputGroupInput** — native input stripped of border and ring (the group provides them)
- **InputGroupTextarea** — same, for textarea
- **InputGroupText** — inline text (prefixes, units) with muted styling

## Examples

### Search

```tsx
<InputGroup>
  <InputGroupAddon>
    <Search />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search..." />
</InputGroup>
```

### Prefix

```tsx
<InputGroup>
  <InputGroupAddon>
    <InputGroupText>https://</InputGroupText>
  </InputGroupAddon>
  <InputGroupInput placeholder="example.com" />
</InputGroup>
```

### Trailing button

```tsx
<InputGroup>
  <InputGroupInput placeholder="Enter email" />
  <InputGroupAddon align="inline-end">
    <InputGroupButton variant="default">Subscribe</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```

### Vertical layout

```tsx
<InputGroup>
  <InputGroupInput placeholder="Type a message" />
  <InputGroupAddon align="block-end">
    <InputGroupButton size="icon-sm">
      <ArrowUpIcon />
    </InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```

### InputGroupInput / InputGroupTextarea

Extend native `input` / `textarea` props. Borders, ring, and background are stripped so the group provides the visual shell.
