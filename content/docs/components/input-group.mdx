```tsx title="input-group.tsx"

```

```tsx title="input-group.tsx"
<InputGroup>
  <InputGroupAddon>
    <Search />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search..." />
</InputGroup>
```

## Anatomy

```tsx
<InputGroup>
  <InputGroupAddon align="inline-start">
    <Search />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon align="inline-end">
    <InputGroupButton>Go</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```

- **InputGroup** — bordered wrapper; auto-sizes height when an addon uses `align="block-start"` / `align="block-end"`
- **InputGroupAddon** — icon, text, or button container; `align` controls position
- **InputGroupButton** — compact button sized for the group; inherits from Frakment `Button`
- **InputGroupInput** — native input stripped of border and ring (the group provides them)
- **InputGroupTextarea** — same, for textarea
- **InputGroupText** — inline text (prefixes, units) with muted styling

Set `data-disabled="true"` on the group, or `disabled` on the control, to dim the whole surface.

```

### Invalid

Set `aria-invalid` on the control to trigger the destructive border and ring on the group.

    defaultValue="Not found"
  />
</InputGroup>
```

## Accessibility

- `InputGroup` wraps a single input or textarea. Do not nest multiple controls.
- Addons are decorative; use `aria-label` on icon-only addons.
- The focus ring applies to the group, not the inner input.

## Best Practices

- **One input per group.** Multiple inputs need multiple groups.
- **Addons align end or start.** Never both around the input.
- **Label the input inside.** Addons are not labels.
- **Keep addons visual.** A button inside an addon is a full Button.
