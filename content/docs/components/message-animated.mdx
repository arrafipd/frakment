Message Animated renders one message from a `UIMessage` with a short fade-and-rise entrance. It pairs with `MessageScroller` to anchor messages as they stream in.

## Usage

```tsx
import { MessageAnimated } from "@/components/ui/message-animated";
```

```tsx
<MessageAnimated message={message} />
```

The `message` prop is a `UIMessage` from the `ai` package. Text is extracted with `getMessageText` from `@frakment/ai`.

## Behavior

- **Entrance animation.** The whole message row fades from `opacity: 0` and rises `y: 8` to `y: 0` over `0.2s` with `easeOut`.
- **Reduced motion.** `prefers-reduced-motion` is respected by Motion automatically — the entrance is skipped.
- **Alignment.** User messages render right-aligned in a bubble; assistant messages render left-aligned on a ghost surface.
- **Scrolling.** When `scrollAnchor` is set, the row is registered as a scroll anchor with `MessageScroller`.

## Accessibility

- Renders inside `MessageScrollerItem`, which carries list semantics.
- The bubble content preserves whitespace with `whitespace-pre-wrap`.
- `prefers-reduced-motion` disables the entrance transition.
