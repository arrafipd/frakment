Trace is the foundational primitive behind [Chain of Thought](/docs/ai-elements/chain-of-thought) and any vertical step list. It composes a flex column of lines, each with an icon, title, and optional status.

## Status

Use `status` on **TraceLine** to convey state without extra markup.

| Status | Effect |
| :-- | :-- |
| `running` | Foreground color, shimmer on title |
| `error` | Destructive color |
| `pending` | 60% opacity |

## API Reference

### Trace / TraceIcon / TraceTitle / TraceDescription

Extend `React.ComponentProps<"div">` / `"span">`. **TraceIcon** is `aria-hidden`. **TraceTitle** wraps its children in a shimmer when the parent line is `running`.

### TraceLine

<PropsTable
  rows={[
    { name: "status", type: "running | error | pending", description: "Controls color and shimmer behavior of the line." },
  ]}
/>

### TraceCollapsible

Extends Radix `Collapsible.Root`. Supports `open`, `defaultOpen`, `onOpenChange`.

### TraceCollapsibleTrigger

Extends Radix `Collapsible.Trigger`. Chevron rotates 90° when open.
### TraceCollapsibleContent

Extends Radix `Collapsible.Content`. Animates height via `motion/react` with `SPRING_SMOOTH` from `@/lib/animation` and re-targets on content growth via `ResizeObserver`. Pass `animateHeight={false}` to opt out.

## Accessibility

- `TraceIcon` is `aria-hidden`. Use `TraceTitle` as the accessible name — write it as a sentence.
- Status is conveyed by icon shape and color, not color alone.
- `prefers-reduced-motion` disables shimmer and collapse animation.

## Best Practices

- **One line per step.** Do not merge unrelated actions into one line.
- **Wrap trace in a collapsible for long runs.** Ten lines collapse the transcript.
- **Mark running steps.** `status="running"` triggers the shimmer and spinner.
- **Keep titles verb-first.** "Ran pnpm test", not "pnpm test status".
