## Anatomy

Trace is a set of composable parts that share a Collapsible context.

- **Trace** - vertical container
- **TraceCollapsible** - one row; provides `open` state to its children
- **TraceLine** - header row for icon and trigger
- **TraceIcon** - leading or trailing icon slot
- **TraceTitle** - primary label
- **TraceDescription** - secondary label or metric
- **TraceCollapsibleTrigger** - header button that toggles the row
- **TraceCollapsibleContent** - body revealed when the row is open

## Accessibility

- Built on Radix Collapsible, exposing `aria-expanded` on the trigger.
- Keyboard: `Enter` and `Space` toggle a row.
- Motion respects `prefers-reduced-motion`.
