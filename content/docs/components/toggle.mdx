Toggle is a two-state button built on the Radix Toggle primitive. It supports `default` and `outline` variants, `sm` / `default` / `lg` sizes, and pressed / disabled states.

## Usage

```tsx title="toggle.tsx"
import { Toggle } from "@/components/ui/toggle";
```

```tsx
<Toggle aria-label="Toggle italic">
  <ItalicIcon />
  Italic
</Toggle>
```

## Anatomy

```tsx
<Toggle>
  <Icon />
  Label
</Toggle>
```

- **Toggle** — Radix `Toggle.Root`; accepts `variant`, `size`, `pressed`, `defaultPressed`, `onPressedChange`
- Icons and text are children; the pressed state styles icon fills via `group-aria-pressed/toggle:`

## Examples

### Outline

Pass `variant="outline"` for a bordered toggle.

<ComponentPreview name="toggle" title="toggle.tsx">
  <ToggleOutline />
</ComponentPreview>

```tsx
<Toggle variant="outline" aria-label="Toggle italic">
  <ItalicIcon />
  Italic
</Toggle>
```

### Text

Default variant — no border, transparent background.

<ComponentPreview name="toggle" title="toggle.tsx">
  <ToggleText />
</ComponentPreview>

```tsx
<Toggle aria-label="Toggle italic">
  <ItalicIcon />
  Italic
</Toggle>
```

### Sizes

`size` accepts `sm`, `default`, and `lg`.

<ComponentPreview name="toggle" title="toggle.tsx">
  <ToggleSizes />
</ComponentPreview>

```tsx
<Toggle size="sm">Small</Toggle>
<Toggle size="default">Default</Toggle>
<Toggle size="lg">Large</Toggle>
```

### Disabled

Set `disabled` on the toggle to lock interaction.

<ComponentPreview name="toggle" title="toggle.tsx">
  <ToggleDisabled />
</ComponentPreview>

```tsx
<Toggle disabled>Disabled</Toggle>
<Toggle variant="outline" disabled>Disabled</Toggle>
```
