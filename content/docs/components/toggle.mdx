Toggle is a two-state button built on the Radix Toggle primitive. It supports `default` and `outline` variants, `sm` / `default` / `lg` sizes, and pressed / disabled states.


```tsx
<Toggle aria-label="Toggle italic">
  <ItalicIcon />
  Italic
</Toggle>
```

## Anatomy

```tsx
<Toggle>
  <Icon />
  Label
</Toggle>
```

- **Toggle** — Radix `Toggle.Root`; accepts `variant`, `size`, `pressed`, `defaultPressed`, `onPressedChange`
- Icons and text are children; the pressed state styles icon fills via `group-aria-pressed/toggle:`

```tsx
<Toggle pressed={pressed} onPressedChange={setPressed} />
```

| Variant | Use case |
| :-- | :-- |

## Accessibility

- `Toggle` renders a button with `aria-pressed`.
- Provide `aria-label` when the toggle is icon-only.
- Keyboard: Space toggles.

## Best Practices

- **Icon-only toggles need a label.** `aria-label` is not optional.
- **Use `ToggleGroup` for multiple toggles.** Standalone toggles read as buttons.
- **Persist the state.** Toggles are stateful, not one-shot.
