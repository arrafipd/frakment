## Keyboard

| Key | Action |
| :-- | :-- |
| `Space` / `Enter` | Toggle the panel |

## Data Attributes

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `collapsible`, `collapsible-trigger`, `collapsible-content` |
| `data-state` | `open` \| `closed` |
| `data-disabled` | `true` |

## Accessibility

- Built on Radix Collapsible; exposes `aria-expanded` and `aria-controls`.
- Keyboard: `Enter` and `Space` toggle the panel.
- Provide a descriptive trigger label or `aria-label`.

## Best Practices

- **Use for optional detail.** Content that must be visible on load belongs on the page.
- **Keep the trigger visible.** Never hide the trigger inside the content.
- **Default closed for long content.** Default open for short, always-relevant blocks.
- **Do not nest collapsibles.** Two levels is hard to track; use Accordion for nested groups.
