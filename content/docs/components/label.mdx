Label renders a Radix `<Label>` primitive that forwards clicks to its associated control via `htmlFor`. Disabled styling is inherited automatically when the wrapped control is disabled.

## Usage

```tsx title="label.tsx"
import { Label } from "@/components/ui/label";
```

```tsx
<Label htmlFor="email">Email</Label>
<Input id="email" type="email" />
```

## Examples

### Required

Append a `*` (or any indicator) inline to signal a required field.

<ComponentPreview name="label" title="label.tsx">
  <LabelRequired />
</ComponentPreview>

```tsx
<Label htmlFor="req">
  Email <span className="text-destructive">*</span>
</Label>
```

### Disabled

When the associated control is disabled, dim the label with `opacity-50` — matching the control.

<ComponentPreview name="label" title="label.tsx">
  <LabelDisabled />
</ComponentPreview>

```tsx
<Label htmlFor="dis" className="opacity-50">Disabled field</Label>
<Input id="dis" disabled />
```

## API Reference

Extends `React.ComponentProps<typeof LabelPrimitive.Root>` from `radix-ui`.

Adds `data-slot="label"` for styling hooks.
