Label renders a Radix `<Label>` primitive that forwards clicks to its associated control via `htmlFor`. Disabled styling is inherited automatically when the wrapped control is disabled.

## Usage

```tsx title="label.tsx"
import { Label } from "@/components/ui/label";
```

```tsx
<Label htmlFor="email">Email</Label>
<Input id="email" type="email" />
```

## Examples

### Required

Append a `*` (or any indicator) inline to signal a required field.

When the associated control is disabled, dim the label with `opacity-50` — matching the control.

```tsx

```

## Accessibility

- `Label` renders a native `<label>`. Always link it to the control via `htmlFor` matching the control's `id`.
- Clicking the label focuses or toggles the associated control. This is the primary benefit for touch users.
- Do not nest interactive content inside `Label`. A link or button inside a label breaks its click behavior.
- When marking a field required, add `aria-required="true"` on the control, not the label alone.

## Best Practices

- **Always link via `htmlFor`.** An unlinked label is decorative; screen readers ignore it.
- **Keep labels short.** One to three words; put detail in `FieldDescription`.
- **Use `Label` for every form control.** `Input`, `Textarea`, `Select`, `Checkbox`, `Switch`.
- **Avoid labels inside tooltips.** They disappear when the user moves away.
- **Mark required fields explicitly.** Use a `*` plus `aria-required` on the control.
