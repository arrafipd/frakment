## Anatomy

Text Flip renders a single element that swaps its content on an interval.

- **TextFlip** - root element; accepts `as` to choose between `p`, `span`, or `code`

## Variants

### Flip

The default variant. Old text exits downward while the new text enters from above, both animated simultaneously via `mode="popLayout"`.

~~~tsx
<TextFlip>{"Build", "Ship", "Iterate"}</TextFlip>
~~~

### Fade

Crossfade where the outgoing text fades out while the incoming text fades in, both visible at the same time. The transition runs on native CSS at 0.6s ease-in-out, so it stays smooth regardless of JS frame budget.

<ComponentPreview name="text-flip" title="text-flip.tsx" previewClassName="h-auto">
  <TextFlipFade />
</ComponentPreview>

~~~tsx
<TextFlip variant="fade" interval={2.2}>
  {"Crafted with care", "Designed for clarity"}
</TextFlip>
~~~

### Blur

Adds a blur ramp on top of the crossfade. Use it for hero headings where you want a cinematic reveal.

  <TextFlipBlur />
</ComponentPreview>

~~~tsx

~~~

Horizontal slide instead of vertical. Suits headlines, notification banners, and tab labels.

Scales from 0.85 to 1 while fading. Compact footprint, good for inline counters and badges.

### Count

Interpolates numeric strings smoothly. Preserves prefix, suffix, decimals, and thousands separators.

<ComponentPreview name="text-flip" title="text-flip.tsx" previewClassName="h-auto">

~~~tsx

~~~

### Roll

Slot-machine roll powered by `@number-flow/react`. Digits spin into place with a smooth vertical mask and eased settle. Control `index` and `paused` to expose Pause and Reset like the hero demo above.

<ComponentPreview name="text-flip" title="text-flip.tsx" previewClassName="h-auto">

~~~tsx

~~~

### Shuffle

Scrambles each character through symbols and capitals before settling to the target letter, left to right across the full duration. Spaces remain visible so word boundaries stay readable.

<ComponentPreview name="text-flip" title="text-flip.tsx" previewClassName="h-auto py-8">
  <TextFlipShuffle />
</ComponentPreview>

~~~tsx
<TextFlip variant="shuffle">{"Build", "Ship", "Iterate"}</TextFlip>
~~~

### Typewriter

Characters appear one at a time from left to right. Set `speed` in milliseconds to control the typing pace.

<ComponentPreview name="text-flip" title="text-flip.tsx" previewClassName="h-auto">
  <TextFlipTypewriter />
</ComponentPreview>

~~~tsx

  {"npm install frakment", "npx frakment add button"}
</TextFlip>
~~~

### Wave

Each character fades in instead of snapping. Softer than plain typewriter, still left-to-right.

<ComponentPreview name="text-flip" title="text-flip.tsx" previewClassName="h-auto">

~~~

## Accessibility

- Wraps the text in a semantic element chosen via `as`.
- Motion respects `prefers-reduced-motion`.
- Keep each phrase short so screen readers announce quickly.

## Best Practices

- **Keep phrases short.** Two to four words per flip; longer clips mid-animation.
- **Pause on hover.** Let users finish reading before the next phrase.
- **Do not use for critical text.** If users might miss it, use static copy.
- **Respect reduced-motion.** Fall back to a static phrase.
