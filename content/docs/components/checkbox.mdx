Checkbox is a Radix primitive styled with Frakment tokens. It supports checked, unchecked, and indeterminate states, and integrates with `Label` for accessible click-through.

## Usage

```tsx title="checkbox.tsx"
import { Checkbox } from "@/components/ui/checkbox";
```

```tsx
<Checkbox defaultChecked />
```

## Examples

### States

Pass `checked="indeterminate"` for a partial-selection state.

<ComponentPreview name="checkbox" title="checkbox.tsx">
  <CheckboxStates />
</ComponentPreview>

```tsx
<Checkbox aria-label="Unchecked" />
<Checkbox aria-label="Checked" defaultChecked />
<Checkbox aria-label="Indeterminate" checked="indeterminate" />
```

### Disabled

<ComponentPreview name="checkbox" title="checkbox.tsx">
  <CheckboxDisabled />
</ComponentPreview>

```tsx
<Checkbox id="c-dis" disabled />
<Label htmlFor="c-dis">Disabled</Label>
```

### With label

Pair with `Label` and matching `id` / `htmlFor` for a click-through row.

<ComponentPreview name="checkbox" title="checkbox.tsx">
  <CheckboxWithLabel />
</ComponentPreview>

```tsx
<div className="flex items-center gap-2">
  <Checkbox id="c-a" defaultChecked />
  <Label htmlFor="c-a">Email notifications</Label>
</div>
```

## API Reference

Extends `React.ComponentProps<typeof CheckboxPrimitive.Root>` from `radix-ui`.

Adds `data-slot="checkbox"` for styling hooks.
