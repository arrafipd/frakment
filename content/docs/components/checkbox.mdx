| Unchecked | default |

| Indeterminate | `checked="indeterminate"` |
| Disabled | `disabled` prop |

| Attribute | Values |
| :-- | :-- |
| `data-slot` | `checkbox` |
| `data-state` | `checked` \| `unchecked` \| `indeterminate` |
| `data-disabled` | `true` |

## Accessibility

- `Checkbox` renders a button with `role="checkbox"` and manages `aria-checked`. Do not add `role` manually.
- Always pair with a `label` or `FieldLabel` using `htmlFor`. Clicking the label toggles the checkbox.
- The indeterminate state is set via `checked="indeterminate"`. It has no user-triggered equivalent; set it when some but not all children are selected.
- `disabled` removes the checkbox from the tab order. If the value is informational, use `readOnly` instead of `disabled`.

## Best Practices

- **One checkbox per independent option.** Do not use it for exclusive choices — use `RadioGroup`.
- **Labels go to the right.** `Checkbox` then `label` is the standard pattern.
- **Instant toggle.** Checkboxes toggle immediately; there is no separate save step.
- **Indeterminate is a display state.** Set it programmatically when a parent has mixed child states.
- **Use `Switch` for immediate settings.** Checkbox reads as "queued until save" to many users.
