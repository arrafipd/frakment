Card is a flexible surface for content and actions. It supports a `size` prop (`default` / `sm`), an auto-spacing variable `--card-spacing` (default 16px, `sm` 12px), and image-friendly slots (`pt-0` / `rounded-t-xl`).

## Anatomy

```tsx
<Card>
  <CardHeader>
    <CardTitle />
    <CardDescription />
    <CardAction />
  </CardHeader>
  <CardContent />
  <CardFooter />
</Card>
```

- **Card** — root surface; accepts `size` (`default` / `sm`), sets `--card-spacing`
- **CardHeader** — grid container; auto-column when `CardAction` is present
- **CardTitle** — heading
- **CardDescription** — muted helper text
- **CardAction** — top-right slot (grid column 2)
- **CardContent** — body; padding via `px-(--card-spacing)`
- **CardFooter** — bottom row; auto border-top + muted background

## Examples

### Small size

Pass `size="sm"` for tighter padding (12px) and smaller title.

```tsx
    <CardDescription>Weekly snapshots.</CardDescription>
  </CardHeader>
  <CardContent>...</CardContent>
  <CardFooter>...</CardFooter>
</Card>
```

### Custom spacing

Override `--card-spacing` via an inline arbitrary class — the entire card (header, content, footer) adapts.

<ComponentPreview name="card" title="card.tsx" previewClassName="h-auto py-8">
  <CardSpacing />
</ComponentPreview>

```tsx
<Card className="[--card-spacing:--spacing(6)]">...</Card>
```

### Edge to edge

Negate `--card-spacing` on `CardContent` (`-mb-(--card-spacing)`, `-mx-(--card-spacing)`) for full-bleed sections like scrollable terms.

<ComponentPreview name="card" title="card.tsx" previewClassName="h-auto py-8">
  <CardEdgeToEdge />
</ComponentPreview>

```tsx
<CardContent className="-mb-(--card-spacing)">
  <div className="-mx-(--card-spacing) px-(--card-spacing) py-4">...</div>
</CardContent>
```

### With image

Any `<img>` as the first child gets `pt-0` + rounded top automatically — no extra classes needed on the image itself.

<ComponentPreview name="card" title="card.tsx" previewClassName="h-auto py-8">
  <CardImage />
</ComponentPreview>

```tsx
<Card className="pt-0">
  <img src="..." alt="..." className="aspect-video w-full object-cover" />
  <CardHeader>...</CardHeader>
</Card>
```

## Accessibility

- `Card` renders a plain `<div>` with `data-slot="card"`. It has no role by default; add one when the card represents a distinct region (e.g. `role="region"` with `aria-labelledby`).
- `CardTitle` renders an `h3`. Use one `CardTitle` per card so document outline stays flat.
- Do not attach `onClick` to the card surface. If the whole card is clickable, wrap it in a link and keep the actions as separate focusable elements.
- Interactive content inside `CardFooter` receives focus in DOM order; keep destructive actions last.

## Best Practices

- **One idea per card.** Split content into multiple cards rather than stacking everything inside one.
- **Do not nest cards.** Use `Separator` to divide sections inside a card.
- **Keep actions in the footer.** `CardFooter` aligns buttons and metadata to the end.
- **Use `CardTitle` as a heading, not a label.** For labels, use `text-sm font-medium` on a span.
- **Avoid full-surface hover unless the whole card is clickable.** Mixed hover states confuse users.
