Breadcrumb shows the path from the site root to the current page. It helps users understand where they are and jump back to any ancestor level.

## Usage

~~~tsx title="breadcrumb.tsx"
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb";
~~~

~~~tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem><BreadcrumbLink href="/">Home</BreadcrumbLink></BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem><BreadcrumbLink href="/components">Components</BreadcrumbLink></BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem><BreadcrumbPage>Breadcrumb</BreadcrumbPage></BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
~~~

## Accessibility

- Wrapper is `<nav aria-label="breadcrumb">`, giving a named landmark.
- Current page uses `aria-current="page"` and is not focusable.
- Separators are `role="presentation"` so they are skipped by screen readers.

## Best Practices

- **Last item is a page, not a link.** Use `BreadcrumbPage`, not `BreadcrumbLink`.
- **Skip the root if obvious.** If the logo links to home, do not repeat "Home".
- **Keep segments short.** "Docs / Button", not "Documentation / Button component".
- **Do not use breadcrumbs for wizard steps.** Use a Stepper instead.
