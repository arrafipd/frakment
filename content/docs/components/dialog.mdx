## Usage

~~~tsx title="dialog.tsx"
import {
  Dialog, DialogClose, DialogContent, DialogDescription,
  DialogFooter, DialogHeader, DialogTitle, DialogTrigger,
} from "@/components/ui/dialog";
~~~

~~~tsx
<Dialog>
  <DialogTrigger asChild>
    <Button>Open</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Title</DialogTitle>
      <DialogDescription>Description</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose asChild>
        <Button variant="outline">Cancel</Button>
      </DialogClose>
      <Button>Save</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
~~~
## Anatomy

- **Dialog** — root; accepts `open` / `onOpenChange`
- **DialogTrigger** — button; use `asChild` to wrap your Button
- **DialogContent** — the modal panel; `showCloseButton` toggles the top-right X
- **DialogHeader** / **DialogFooter** — layout slots
- **DialogTitle** / **DialogDescription** — required for accessibility
- **DialogClose** — dismiss button; use `asChild`

## Accessibility

- Focus is trapped inside the dialog while open.
- `DialogTitle` and `DialogDescription` are announced to screen readers.
- `Escape` closes the dialog unless prevented.
- Clicking the backdrop closes the dialog.

## Best Practices

- **Do not use a dialog for navigation.** Use a Sheet or a new route instead.
- **Keep content short.** If it needs to scroll, it might belong on its own page.
- **Provide multiple exits.** Cancel in the footer, Escape key, and outside click.
- **Put the destructive action last.** Primary on the right, destructive on the far right.
