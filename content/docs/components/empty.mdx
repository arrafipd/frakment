Empty is a composable placeholder for zero-data screens — inbox, search results, project lists, first-run onboarding. It renders a dashed surface with a stacked icon, title, description, and optional call-to-action.

## Anatomy

```tsx
<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon" />
    <EmptyTitle />
    <EmptyDescription />
  </EmptyHeader>
  <EmptyContent />
</Empty>
```

- **Empty** — centered flex column with dashed border, `rounded-xl`, padding, and `text-balance`
- **EmptyHeader** — max-width container that keeps title and description centered
- **EmptyMedia** — icon container; `variant="icon"` gives a rounded square with muted background
- **EmptyTitle** — small medium-weight heading
- **EmptyDescription** — muted secondary text; accepts links
- **EmptyContent** — full-width content block for actions below the header

## Accessibility

- The `EmptyTitle` renders as a heading; document outline stays flat.
- Pair the icon with the title; icon-only empty states are invisible to screen readers.
- Provide a primary action inside the empty state when possible.

## Best Practices

- **Explain the empty state.** "No messages" beats "Empty".
- **Offer the first action.** A button or link beats a dead end.
- **Keep it small.** Empty states should not fill the whole page unless the page is empty.
- **Do not hide the empty state during loading.** Use a Skeleton instead.
