## Usage

```tsx title="select.tsx"
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";
```

```tsx
<Select>
  <SelectTrigger>
    <SelectValue placeholder="Select a fruit" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="apple">Apple</SelectItem>
    <SelectItem value="banana">Banana</SelectItem>
  </SelectContent>
</Select>
```

> **Note:** `Select` does **not** accept an `items` prop. Pass `value` / `defaultValue` / `onValueChange` on the root, and never pass an empty string to `value` — Radix Select treats `""` as a special state.

## Anatomy

```tsx
<Select>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel />
      <SelectItem />
    </SelectGroup>
  </SelectContent>
</Select>
```

- **Select** — Radix `Select.Root`; accepts `value`, `defaultValue`, `onValueChange`, `disabled`
- **SelectTrigger** — the button that opens the dropdown; accepts `aria-invalid`
- **SelectValue** — renders the current value or `placeholder`
- **SelectContent** — the popup; portals into `document.body`
- **SelectItem** — a selectable option; must have a non-empty `value`
- **SelectGroup** / **SelectLabel** — group related items with a heading
- **SelectSeparator** / **SelectScrollUpButton** / **SelectScrollDownButton** — additional Radix helpers

## API Reference

### Select

Extends Radix `Select.Root`.

  rows={[

    { name: "name", type: "string", description: "Submitted with the form." },

  ]}

### SelectTrigger

Renders the trigger button. Accepts `size` (`sm` | `default`) and `className`.

### SelectContent

Extends Radix `Select.Content`. Renders inside a portal. Accepts `position` (`item-aligned` | `popper`) and `side`.

### SelectItem

Extends Radix `Select.Item`. Accepts `value` (required) and `disabled`.

### SelectValue

Renders the selected label. Accepts `placeholder` for the empty state.

### SelectGroup / SelectLabel

`SelectGroup` clusters items under a heading rendered by `SelectLabel`.

## Accessibility

- `SelectTrigger` renders a button with `role="combobox"` and `aria-expanded`. Do not add `role` manually.
- Pair with a `Label` or `FieldLabel` using `htmlFor` so screen readers announce the field name.
- `SelectItem` accepts `disabled`; disabled items remain in the list for context but are not focusable.
- When the trigger is inside a form, always set `name` so the value submits correctly.

## Best Practices

- **Use Select for long lists.** Radio Group is better for under five options.
- **Always show a placeholder.** `SelectValue placeholder` makes the empty state clear.
- **Group long lists.** Use `SelectGroup` and `SelectLabel` to organize by category.
- **Do not use Select for navigation.** Use a link or a Button with a dropdown menu.
- **Keep items scannable.** Sort alphabetically or logically; do not mix sort orders within one group.
