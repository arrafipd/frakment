## Usage

```tsx title="select.tsx"
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";
```

```tsx
<Select>
  <SelectTrigger>
    <SelectValue placeholder="Select a fruit" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="apple">Apple</SelectItem>
    <SelectItem value="banana">Banana</SelectItem>
  </SelectContent>
</Select>
```

> **Note:** `Select` does **not** accept an `items` prop. Pass `value` / `defaultValue` / `onValueChange` on the root, and never pass an empty string to `value` — Radix Select treats `""` as a special state.

## Anatomy

```tsx
<Select>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel />
      <SelectItem />
    </SelectGroup>
  </SelectContent>
</Select>
```

- **Select** — Radix `Select.Root`; accepts `value`, `defaultValue`, `onValueChange`, `disabled`
- **SelectTrigger** — the button that opens the dropdown; accepts `aria-invalid`
- **SelectValue** — renders the current value or `placeholder`
- **SelectContent** — the popup; portals into `document.body`
- **SelectItem** — a selectable option; must have a non-empty `value`
- **SelectGroup** / **SelectLabel** — group related items with a heading
- **SelectSeparator** / **SelectScrollUpButton** / **SelectScrollDownButton** — additional Radix helpers

## API Reference

All parts extend their corresponding Radix `Select` primitives. Frakment adds `data-slot="select-*"` markers on each part for styling hooks.
