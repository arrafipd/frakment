Dropdown Menu is a compound Radix primitive. It supports plain items, groups with labels, separators, nested submenus, checkbox / radio items, icons, and destructive variants.

## Usage

```tsx title="dropdown-menu.tsx"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button variant="outline">Open</Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Profile</DropdownMenuItem>
    <DropdownMenuItem>Settings</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

## Anatomy

```tsx
<DropdownMenu>
  <DropdownMenuTrigger asChild />
  <DropdownMenuContent>
    <DropdownMenuLabel />
    <DropdownMenuItem />
    <DropdownMenuSeparator />
    <DropdownMenuSub>
      <DropdownMenuSubTrigger />
      <DropdownMenuSubContent />
    </DropdownMenuSub>
  </DropdownMenuContent>
</DropdownMenu>
```
