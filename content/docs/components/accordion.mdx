## Usage

~~~tsx title="accordion.tsx"
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
~~~

~~~tsx title="accordion.tsx"
<Accordion collapsible defaultValue="shipping" type="single">
  <AccordionItem value="shipping">
    <AccordionTrigger>What are your shipping options?</AccordionTrigger>
    <AccordionContent>
      Standard, express, and overnight options available.
    </AccordionContent>
  </AccordionItem>
</Accordion>
~~~

## Anatomy

Accordion is a stack of items, each with a trigger and a panel.

<ComponentPreview name="accordion" title="accordion.tsx" previewClassName="h-auto py-8">
  <AccordionDemo />
</ComponentPreview>

- **Accordion** - root container; controls single or multiple expansion
- **AccordionItem** - one collapsible section; carries a unique `value`
- **AccordionTrigger** - header button; rotates the chevron on open
- **AccordionContent** - panel that animates height between states

## Accessibility

- Built on Radix Accordion, which follows the WAI-ARIA disclosure pattern.
- Triggers expose `aria-expanded` and `aria-controls` automatically.
- Keyboard: `Enter` and `Space` toggle an item; `ArrowUp` and `ArrowDown` move focus.
- Use descriptive trigger text, not icon-only headers.

## Best Practices

- **Keep content short per section.**
- **Use `type="single"` for FAQ-style lists.**
- **Use `type="multiple"` for settings panels.**
- **Reserve `defaultValue` for one item.**
