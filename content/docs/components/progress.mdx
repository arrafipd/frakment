## Usage

```tsx title="progress.tsx"
import { Progress } from "@/components/ui/progress";

<Progress value={60} />
```

The bar animates from 0 to the new value. Drop `transition-transform duration-500 ease-out` on the indicator to make it instant.

## With label and value

Pass `ProgressLabel` and `ProgressValue` as children to render a header row above the bar. `ProgressValue` reads the current value from context and renders `{value}%`.

<ComponentPreview name="progress" title="progress-with-label.tsx">
  <ProgressWithLabel />
</ComponentPreview>

```tsx
<Progress value={56}>
  <ProgressLabel>Upload progress</ProgressLabel>
  <ProgressValue />
</Progress>
```

## Controlled

<ComponentPreview name="progress" title="progress-controlled.tsx">

```tsx
const [value, setValue] = React.useState(50);

<Progress value={value} />
<input
  type="range"
  min={0}
  max={100}
  value={value}
  onChange={(event) => setValue(Number(event.target.value))}
/>
```

### ProgressLabel

Extends `React.ComponentProps<"span">`. Renders the label on the left of the header row.

### ProgressValue

Extends `React.ComponentProps<"span">`. Reads `value` from `ProgressContext` and renders `{value}%`.

## Accessibility

- Radix `Progress.Root` exposes `role="progressbar"`, `aria-valuenow`, and `aria-valuemax` automatically.
- Pair the bar with `ProgressLabel` when the progress is not self-describing.
- Do not rely on color alone. Use `ProgressValue` to show the numeric value.
