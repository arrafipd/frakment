## Anatomy

A button is a single element with an optional icon on either side of a text label.

<ComponentPreview name="button" title="button.tsx">
  <div className="flex flex-wrap items-center justify-center gap-3">
    <Button>Text only</Button>
    <Button>
      <CheckIcon />
      With icon
    </Button>
    <Button size="icon" aria-label="Add">
      <PlusIcon />
    </Button>
  </div>
</ComponentPreview>

- **Surface** — background, border, and radius following the variant
- **Text** — 14px, medium weight, nowrap
- **Icon** — sized to 16px by `[&_svg]:size-4`

## Variants

| Variant | Use case |
| :-- | :-- |
| `default` | Primary action |
| `secondary` | Secondary action |
| `outline` | Bordered neutral |
| `ghost` | Minimal, hover only |
| `destructive` | Irreversible action |
| `link` | Inline link styling |

Set with the `variant` prop:

```tsx
<Button variant="outline">Cancel</Button>
```

## Links

Use `href` to render the button as a native anchor. The component renders an `<a>` element instead of a `<button>`, so `target`, `rel`, and `download` work as expected. All variants, sizes, and icon layouts work on links.

```tsx
<Button href="/docs">Read the docs</Button>
<Button href="https://github.com" target="_blank" rel="noopener noreferrer">
  GitHub
</Button>
```

### Router links

For client-side navigation, use the router link component directly and apply the button styles with `buttonVariants`. This preserves prefetching, scroll restoration, and route-level transitions that the router provides.

Next.js App Router:

```tsx
import Link from "next/link";
import { buttonVariants } from "@/components/ui/button";

<Link href="/pricing" className={buttonVariants({ variant: "outline", size: "sm" })}>
  Pricing
</Link>
```

React Router:

```tsx
import { Link } from "react-router";
import { buttonVariants } from "@/components/ui/button";

<Link to="/pricing" className={buttonVariants({ variant: "outline", size: "sm" })}>
  Pricing
</Link>
```

TanStack Router:

```tsx
import { Link } from "@tanstack/react-router";
import { buttonVariants } from "@/components/ui/button";

<Link to="/pricing" className={buttonVariants({ variant: "outline", size: "sm" })}>
  Pricing
</Link>
```

### Which approach to pick

| Case | Approach |
| --- | --- |
| Static site, plain HTML, external URL | `<Button href="...">` |
| Next.js App Router or Pages Router | `<Link className={buttonVariants()}>` |
| React Router or TanStack Router | `<Link className={buttonVariants()}>` |
| Triggers an action, not navigation | `<Button onClick={...}>` |

### buttonVariants

The `buttonVariants` helper returns the class string for any variant and size. Use it to apply button styles to a router link component.

```tsx
import { buttonVariants } from "@/components/ui/button";

<a className={buttonVariants({ variant: "outline", size: "sm" })} href="/docs">
  Read the docs
</a>
```

## Accessibility

- Set `type="button"` on buttons that are not intended to submit a form.
- Provide an `aria-label` on icon-only buttons.
- `disabled` removes the button from the tab order.
- Color contrast is maintained by design tokens. Run your own contrast check for custom tokens.

## Best Practices

- **Use one primary button per surface.**
- **Prefer `size="sm"` inside toolbars.**
- **Never rely on color alone.**
- **Use `href` for static links, `buttonVariants` for router links.**
- **Reserve `destructive` for irreversible actions.**
