Textarea is a styled native `<textarea>` with `field-sizing-content` for automatic height, a consistent focus ring, and disabled / invalid states. Every native attribute is forwarded to the underlying `<textarea>`.

## Accessibility

- `Textarea` renders a native `<textarea>`. Always pair with a `Label` or `FieldLabel`.
- `rows` sets the initial height; the textarea grows with content when `field-sizing-content` is applied.
- Set `aria-invalid` and `aria-describedby` on error, same as `Input`.
- Provide a character count via `aria-describedby` when a hard limit exists.

## Best Practices

- **Set a sensible rows default.** Two to four rows is enough for most forms.
- **Auto-grow with care.** `field-sizing-content` is convenient but can push the submit button off-screen in long replies.
- **Add a character count** when a limit exists.
- **Keep the submit shortcut consistent.** `Cmd+Enter` or `Ctrl+Enter` sends; `Enter` inserts a newline.
- **Do not use Textarea for a single line.** Use `Input` instead.
