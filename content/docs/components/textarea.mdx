Textarea is a styled native `<textarea>` with `field-sizing-content` for automatic height, a consistent focus ring, and disabled / invalid states. Every native attribute is forwarded to the underlying `<textarea>`.


- **Textarea** — native `<textarea>` with `data-slot="textarea"`, `field-sizing-content`, `min-h-16`, and Frakment focus / disabled / invalid styling

## Examples

### Auto-grow

Because of `field-sizing-content`, the textarea grows to fit its content without JavaScript. Set `rows` for a minimum height.

<ComponentPreview
  name="textarea"
  title="textarea.tsx"
  previewClassName="h-auto py-8"
>
  <TextareaAutogrow />
</ComponentPreview>

```tsx
<Textarea
  placeholder="Type a long message..."
  defaultValue="field-sizing-content makes this grow automatically."
/>
```

### Disabled

<ComponentPreview
  name="textarea"
  title="textarea.tsx"
  previewClassName="h-auto py-8"
>
  <TextareaDisabled />
</ComponentPreview>

```tsx
<Textarea
  placeholder="Disabled textarea"
  disabled
  defaultValue="This field is disabled."
/>
```

### Invalid

Set `aria-invalid` on the textarea to trigger the destructive border and ring.

<ComponentPreview
  name="textarea"
  title="textarea.tsx"
  previewClassName="h-auto py-8"
>
  <TextareaInvalid />
</ComponentPreview>

```tsx
<Textarea
  placeholder="Invalid"
  aria-invalid
  defaultValue="This content is not allowed."
/>
```

### With Field

Compose with `Field` for a label and description around the textarea.

<ComponentPreview
  name="textarea"
  title="textarea.tsx"
  previewClassName="h-auto py-8"
>
  <TextareaField />
</ComponentPreview>

```tsx
<Field>
  <FieldLabel htmlFor="feedback">Feedback</FieldLabel>
  <Textarea id="feedback" placeholder="Share your thoughts..." rows={4} />
  <FieldDescription>We read every message.</FieldDescription>
</Field>
```

## API Reference

Extends `React.ComponentProps<"textarea">`. Every native attribute is forwarded to the underlying `<textarea>`.

Adds `data-slot="textarea"` for styling hooks.
