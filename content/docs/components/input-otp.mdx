Input OTP renders a one-time password field with real input handling for paste, backspace, and arrow keys. Each slot is a separate visual box, but the underlying input is a single element for form submission.

## Anatomy

- **InputOTP** - root wrapper; forwards every prop from `input-otp`
- **InputOTPGroup** - visually groups adjacent slots
- **InputOTPSlot** - one character box; `index` is required
- **InputOTPSeparator** - visual divider between groups

## Accessibility

- The wrapper renders a real `<input>` with `inputmode="numeric"` for mobile keyboards.
- Slots expose `data-active` and `data-invalid` for styling, but the input itself carries `aria-invalid`.
- Paste, backspace, and arrow navigation are handled automatically.
- Pair with `FieldLabel htmlFor` and `id` for labelled forms.

## Best Practices

- **Use `maxLength` matching the code length.** Do not let the input grow arbitrarily.
- **Group visually, not semantically.** 3 + 3 reads better than 6 in one row.
- **Auto-focus the first slot on mount.** Reduces taps on mobile.
- **Paste support is required.** Users copy codes from messages; paste should fill every slot.
