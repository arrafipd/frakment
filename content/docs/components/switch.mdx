Switch is a Radix toggle styled with Frakment tokens. Pair it with `Label` (via `htmlFor`) for accessible click-through, or wrap it in `Field` for larger settings rows.

## Examples

### Checked

Use `defaultChecked` for uncontrolled initial state, or `checked` / `onCheckedChange` for a controlled switch.

<ComponentPreview name="switch" title="switch.tsx">
  <SwitchChecked />
</ComponentPreview>

```tsx
<Switch id="s-wifi" defaultChecked />
<Label htmlFor="s-wifi">Wi-Fi</Label>
```

### Disabled

<ComponentPreview name="switch" title="switch.tsx">
  <SwitchDisabled />
</ComponentPreview>

```tsx
<Switch id="s-dis" disabled />
<Label htmlFor="s-dis" className="opacity-50">Disabled</Label>
```

### With description

For settings rows with a title and helper text, compose with `Field` and `FieldContent` (see Field docs) — or lay out manually as below.

## API Reference

Extends `React.ComponentProps<typeof SwitchPrimitive.Root>` from `radix-ui`.

Adds `data-slot="switch"` on the root and `data-slot="switch-thumb"` on the thumb.
