## Usage

~~~tsx title="pagination.tsx"

  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationPrevious,
  PaginationNext,
} from "@/components/ui/pagination";
~~~

~~~tsx
<Pagination>
  <PaginationContent>
    <PaginationItem><PaginationPrevious href="#" /></PaginationItem>
    <PaginationItem><PaginationLink href="#">1</PaginationLink></PaginationItem>
    <PaginationItem><PaginationNext href="#" /></PaginationItem>
  </PaginationContent>
</Pagination>
~~~

## Anatomy

- **Pagination** - `<nav>` wrapper with `aria-label`
- **PaginationContent** - list container
- **PaginationItem** - one entry; usually wraps a link or ellipsis
- **PaginationLink** - `<a>` styled as a button; `isActive` marks the current page
- **PaginationPrevious** / **PaginationNext** - labeled arrow links
- **PaginationEllipsis** - visual skip indicator

## Accessibility

- Uses `<nav>` with `aria-label="pagination"` for landmark navigation.
- Active page sets `aria-current="page"`.
- Previous and Next set `aria-label="Go to previous page"` and `aria-label="Go to next page"`.
