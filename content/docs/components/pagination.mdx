## Accessibility

- Uses `<nav>` with `aria-label="pagination"` for landmark navigation.
- Active page sets `aria-current="page"`.
- Previous and Next set `aria-label="Go to previous page"` and `aria-label="Go to next page"`.

## Best Practices

- **Hide when total is one page.** Pagination with a single page is noise.
- **Show first, last, current, and neighbors.** Skip the middle with an ellipsis.
- **Keep page size in the URL.** Deep links and back button should work.
- **Use pagination, not infinite scroll, for tables.** Users need to jump around.
