## Anatomy

Tabs is a root paired with a list of triggers and matching panels.

- **Tabs** - root container; carries `defaultValue` or controlled `value`
- **TabsList** - row of triggers
- **TabsTrigger** - one button per panel; carries a unique `value`
- **TabsContent** - panel revealed when its `value` matches the active tab

## Accessibility

- Built on Radix Tabs, following the WAI-ARIA tabs pattern.
- Triggers expose `role="tab"` and `aria-selected`.
- Keyboard: `ArrowLeft` and `ArrowRight` move between triggers.

## Best Practices

- **Keep tabs to three or four.** More tabs become a nav, not a tab list.
- **Pick a default.** Empty tab groups confuse users about the current state.
- **Do not nest tabs.** Nested tabs lose context; use a segmented control instead.
- **Do not lazy-load the first tab.** The default tab should not flash.
