Button Group merges adjacent buttons into a single bordered unit. It removes inner radii and doubles the border weight so members read as one control.

## Anatomy

- **ButtonGroup** - wrapper that removes inner radii and merges borders
- **ButtonGroupText** - non-interactive text node inside a group
- **ButtonGroupSeparator** - vertical divider between buttons

## Accessibility

- Renders `role="group"` on the wrapper.
- Every icon-only button must have `aria-label`.
- Groups read as a single control to screen readers when the role is set.

## Best Practices

- **Group related actions.** A Button Group is for actions that share context, not unrelated buttons.
- **Keep sizes consistent.** Mixing `sm` and `default` breaks the shared border.
- **Use `separator` between unrelated pairs.** A vertical divider clarifies intent.
- **Do not nest Button Groups.** Split into two groups instead.
