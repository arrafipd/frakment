Message Scroller wraps a chat transcript in a scroll container that:

- Anchors each user turn so streaming replies never push it out of view
- Follows streamed content automatically while you are at the live edge
- Stops following when you scroll up, resumes when you scroll back down
- Tracks visibility per item (for impressions, lazy rendering, mark-as-read)

It is a thin shell over `@shadcn/react/message-scroller` — the engine lives in that package. The wrapper adds `data-slot` attributes and the Tailwind classes Frakment components expect.

## Usage

```tsx title="chat.tsx"
import {
  MessageScrollerProvider,
  MessageScroller,
  MessageScrollerViewport,
  MessageScrollerContent,
  MessageScrollerItem,
  MessageScrollerButton,
} from "@/components/ui/message-scroller";

export function Chat({ messages }: { messages: ChatMessage[] }) {
  return (
    <MessageScrollerProvider>
      <MessageScroller>
        <MessageScrollerViewport>
          <MessageScrollerContent>
            {messages.map((m) => (
              <MessageScrollerItem key={m.id} scrollAnchor={m.role === "user"}>
                {m.content}
              </MessageScrollerItem>
            ))}
          </MessageScrollerContent>
        </MessageScrollerViewport>
        <MessageScrollerButton />
      </MessageScroller>
    </MessageScrollerProvider>
  );
}
```

## Anatomy

```tsx
<MessageScrollerProvider>
  <MessageScroller>
    <MessageScrollerViewport>
      <MessageScrollerContent>
        <MessageScrollerItem scrollAnchor />
        <MessageScrollerItem />
      </MessageScrollerContent>
    </MessageScrollerViewport>
    <MessageScrollerButton />
  </MessageScroller>
</MessageScrollerProvider>
```

- **MessageScrollerProvider** — owns scroll state; wraps the whole tree.
- **MessageScroller** — relative flex column, `overflow-hidden`.
- **MessageScrollerViewport** — the scroll element; handles anchoring and stick-to-bottom.
- **MessageScrollerContent** — vertical flex column with `gap-6`.
- **MessageScrollerItem** — content-visibility optimization; pass `scrollAnchor` on user turns.
- **MessageScrollerButton** — floating "jump to latest/start" pill; shows only when scrolled away.

## Anchoring

Pass `scrollAnchor` on the item that should stay pinned when new content arrives. For chat, anchor the **user's question** — the assistant's streaming reply then appears below without pushing the question off-screen.

```tsx
<MessageScrollerItem scrollAnchor={message.role === "user"}>
```

If you skip anchoring, the scroller follows the top of the container and replies will push the question out of view during streaming.

## Streaming

The viewport auto-follows streamed content only when you are within a small threshold of the bottom. Scroll up and the viewport stops following; scroll back down and it resumes. No props needed.

To react to the state in your UI (for example, show a "new message" badge):

```tsx title="scroll-status.tsx"
import { useMessageScrollerScrollable } from "@/components/ui/message-scroller";

function ScrollStatus() {
  const { isAtEnd } = useMessageScrollerScrollable();
  return <span>{isAtEnd ? "Live" : "Reading history"}</span>;
}
```

## Visibility

Track which items are in the viewport (impressions, lazy rendering, mark-as-read):

```tsx title="tracked-item.tsx"
import { useMessageScrollerVisibility } from "@/components/ui/message-scroller";

function TrackedItem({
  id,
  children,
}: {
  id: string;
  children: React.ReactNode;
}) {
  const { ref } = useMessageScrollerVisibility({
    onVisibilityChange: (visible) => {
      if (visible) markRead(id);
    },
  });
  return <MessageScrollerItem ref={ref}>{children}</MessageScrollerItem>;
}
```

## Scroll Button

`MessageScrollerButton` renders a floating pill that appears when the viewport is scrolled away from either edge. Defaults: `variant="secondary"`, `size="icon-sm"`.

- `direction="end"` (default) — bottom, "jump to latest".
- `direction="start"` — top, "jump to start".

The button uses the Frakment [Button](/docs/components/button) component. Because `message-scroller` declares `registryDependencies: ["button"]`, running `npx frakment add message-scroller` also installs `button`.

## API Reference

### MessageScrollerProvider

Extends the primitive provider from `@shadcn/react/message-scroller`. Owns scroll state.

### MessageScroller / MessageScrollerViewport / MessageScrollerContent

Extend `React.ComponentProps<"div">` from the primitive. Each adds a `data-slot` attribute for styling.

### useMessageScroller

Low-level hook from `@shadcn/react/message-scroller`. Rarely needed directly.

### useMessageScrollerScrollable

Returns `{ isAtStart, isAtEnd }` for the current viewport.

### useMessageScrollerVisibility

Returns a `ref` and calls `onVisibilityChange(visible)` when the item enters or leaves the viewport. Uses `IntersectionObserver`.

## Accessibility

- `MessageScrollerButton` includes `sr-only` text — "Scroll to end" / "Scroll to start".
- The button only intercepts clicks when active (`data-active="true"`); when hidden, `pointer-events: none`.
- `prefers-reduced-motion` shortens the button transition. The scroll animation respects the user's `scroll-behavior` setting.
