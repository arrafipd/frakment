Stack Trace renders a failed command as a collapsible trace. The error message sits at the top in destructive color, app frames are links to the file, and framework frames from `node_modules` or `node:` collapse into a monospace list.

Stack Trace is a **composition**, not a primitive. It composes [Trace](/docs/components/trace) and [Code Block](/docs/components/code-block) and streams failures through a chat transport.

          <ol />
        </TraceCollapsibleContent>
      </TraceCollapsible>
    </Trace>
  </TraceCollapsibleContent>
</TraceCollapsible>
~~~

- **TraceCollapsibleTrigger** — the header row, marked `status="error"`
- **TraceCollapsibleContent** — the full trace block
- **Trace** — nested list of frames
- **`<a>` + TraceLine** — one app frame, links to the file and line
- **Nested TraceCollapsible** — framework frames, collapsed by default

## Parsing frames

Split the stack into the error line and the frame lines, then parse each frame with a regex. V8 frames look like `at name (file:line:col)`. Frames from `node_modules` or `node:` are internal and collapse together.

~~~ts title="stack-trace.ts"
function parseFrame(line: string) {
  const match = line.match(/^at (.+) \((.+):(\d+):(\d+)\)$/)

  return {
    line,
    name: match?.[1],
    file: match?.[2],
    lineNumber: match?.[3],
    internal: line.includes("node_modules") || line.includes("node:"),
  }
}
~~~

## With command output

Successful commands render their stdout in a [Code Block](/docs/components/code-block). The failed command renders the stack trace in place. The demo alternates between the two so the transition is visible on replay.

## Accessibility

- Each app frame is a link. Add `target` and `rel` if the file opens outside the app.
- The framework frames are plain text in an `<ol>`. Screen readers announce the list position.
- The error line is text, not an icon. Color is a secondary signal.
- `prefers-reduced-motion` disables collapse animation.

## Best Practices

- **Show app frames first.** Framework frames are noise for most debugging.
- **Collapse the framework list.** Users only expand it when the app frame is not enough.
- **Link app frames to source.** A `#file:line` anchor is enough for local dev.
- **Pair with a plain-text summary.** The stack is evidence, not the answer.
