Subagent renders a delegated task as a live trace. The parent message holds a `researchAgent` tool call, the subagent streams its own tool calls as partial output, and the final report lands at the bottom. Every step updates in place.

Subagent is a **composition**, not a primitive. It composes [Trace](/docs/components/trace) and [Code Block](/docs/components/code-block) and streams nested tool calls through a chat transport.

- **TraceCollapsible** — the subagent run, one per delegation

- **TraceLine** — a single step, marked `running` while the subagent is still working

## Streaming partial output

The parent calls `writer.tool("researchAgent", ...)` and then emits partial outputs with `{ preliminary: true }`. Each partial output is a full subagent message with one more step completed. The `preliminary` flag keeps the call open until the final output lands.

~~~ts title="subagent.ts"
const subagent = writer.tool("researchAgent", { input: { task } })

steps.forEach((_, index) => {
  subagent.output(getSubagentMessage(index), { preliminary: true })
  writer.sleep(1000)
})

subagent.output(getSubagentMessage(steps.length, report))
~~~

## Running

While the subagent is still working, the header shimmers and the active step spins. The parent message stays open so the user can follow along.

## Accessibility

- The status icon is decorative. The `TraceTitle` carries the state.
- While running, `aria-live="polite"` on the content region announces step changes.
- Each step row is text, not an icon. Color is a secondary signal.
- `prefers-reduced-motion` disables the spinner and collapse animation.

## Best Practices

- **Stream partial output.** Users want to see the subagent think, not wait for the final message.
- **Collapse the subagent after it finishes.** Long runs crowd the transcript.
- **Surface the model and tools.** A badge row makes the subagent auditable.
- **Keep the report short.** One paragraph, not a summary of every step.
