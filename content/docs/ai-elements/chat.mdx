A complete chat surface wired with `@ai-sdk/react` and Frakment primitives. Messages animate on entry, reasoning appears as a collapsible trace, tool calls render as code blocks, and the transcript stays anchored to the latest message.

Chat is not a single component — it composes **Message Scroller**, **Message**, **Bubble**, and **Input Group** into one surface. Install the primitives, then assemble them the same way the demo does.

## Usage

Wire the chat engine from `@frakment/ai` and render messages with the composed primitives.

```tsx title="chat.tsx"
import { useChat } from "@ai-sdk/react";
import type { UIDataTypes, UIMessage } from "ai";

import { createChat } from "@/lib/ai";

type ChatMessage = UIMessage<
  unknown,
  UIDataTypes,
  { runCommand: { input: { command: string }; output: { stdout: string } } }
>;

const chat = createChat<ChatMessage>()
  .user("Run the tests.")
  .assistant(({ writer }) => {
    writer
      .tool("runCommand", { input: { command: "pnpm test" } })
      .output({ stdout: "15 passed" });
    writer.text("Tests pass.");
  });

const transport = chat.transport({ delayMs: 16 });

export function MyChat() {
  const { messages, sendMessage, status } = useChat({ transport });
  // render messages with MessageScroller + Message + Bubble
}
```

## Anatomy

The demo composes seven primitives. Each one is documented on its own page.

```tsx title="chat.tsx"
<MessageScrollerProvider>
  <MessageScroller>
    <MessageScrollerViewport>
      <MessageScrollerContent>
        <MessageScrollerItem>
          <Message>
            <MessageContent>
              <Bubble>
                <BubbleContent />
              </Bubble>
            </MessageContent>
          </Message>
        </MessageScrollerItem>
      </MessageScrollerContent>
    </MessageScrollerViewport>
    <MessageScrollerButton />
  </MessageScroller>

  <InputGroup>
    <InputGroupTextarea />
    <InputGroupAddon>
      <DropdownMenu>...</DropdownMenu>
      <InputGroupButton type="submit" />
    </InputGroupAddon>
  </InputGroup>
</MessageScrollerProvider>
```

- **MessageScroller** — scroll-aware transcript viewport with sticky scroll button.
- **Message**, **Bubble** — user and assistant turns.
- **Trace**, **TraceCollapsible** — reasoning and tool-call steps inside an assistant message.
- **CodeBlock** — renders tool output.
- **InputGroup** — the composer with textarea, addon buttons, and send action.
- **Empty** — zero-state before the first message.

## Animation

Message rows animate through variants defined in `lib/message-animations.ts`. Motion is skipped when the user prefers reduced motion.

```tsx title="chat.tsx"
import { MESSAGE_ANIMATIONS } from "@/lib/message-animations";
import { motion, useReducedMotion } from "motion/react";

const shouldReduceMotion = useReducedMotion();

<motion.div
  animate={shouldReduceMotion ? undefined : "animate"}
  initial={shouldReduceMotion ? undefined : "initial"}
  variants={MESSAGE_ANIMATIONS["slide-up"].variants}
>
  <Message>...</Message>
</motion.div>
```

Each variant exposes `initial` and `animate` states that plug into `motion.div`. Add a new variant by extending the object — the `MessageAnimation` type covers all keys.

## Reasoning traces

Reasoning and tool calls render as nested `TraceCollapsible` items inside the assistant message. The line auto-expands while streaming and collapses when done.

```tsx title="chat.tsx"
<Trace>
  {steps.map((part) => (
    <TraceCollapsible key={part.id}>
      <TraceCollapsibleTrigger>
        <TraceLine status={running ? "running" : undefined}>
          <TraceIcon>{running ? <LoaderCircleIcon /> : <CircleCheckIcon />}</TraceIcon>
          <TraceTitle>{running ? "Thinking" : "Thought"}</TraceTitle>
        </TraceLine>
      </TraceCollapsibleTrigger>
      <TraceCollapsibleContent>{part.text}</TraceCollapsibleContent>
    </TraceCollapsible>
  ))}
</Trace>
```

## Replacing the script

The demo ships with a scripted `chat` built from `createChat`. Replace it with a real transport:

```tsx title="chat.tsx"
import { useChat } from "@ai-sdk/react";

const { messages, sendMessage, status } = useChat({
  transport: yourTransport,
});
```

The rendered components do not assume the scripted transport. Any `UIMessage[]` works.
