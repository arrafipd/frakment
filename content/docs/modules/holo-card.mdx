Holo Card renders a surface under a procedural foil layer that shifts as the pointer moves or the device tilts. The default card layout shows a chip and a brand mark; pass a `HoloCardImage` child (or `variant="image"`) to render artwork instead. The foil is drawn with WebGL2.

## Usage

```tsx title="holo-card.tsx"
import { HoloCard, HoloCardImage } from "@/components/ui/holo-card";
```

Card mode is the default. Pass a `logo` to brand the bottom-right corner.

```tsx title="holo-card.tsx"
<HoloCard logo={<MyLogo />} />
```

Image mode keeps the artwork-first layout. Passing a `HoloCardImage` child (or `variant="image"`) switches the card into image mode.

```tsx title="holo-card.tsx"
<HoloCard variant="image">
  <HoloCardImage alt="Pikachu" src="/card.avif" />
</HoloCard>
```

`HoloCard` owns pointer tracking, tilt, device orientation, and foil rendering. `HoloCardImage` is a marker component that supplies `src` and `alt` to the parent.

## Anatomy

```tsx title="holo-card.tsx"
<HoloCard logo={<MyLogo />} preset="bursts" />
```

- **HoloCard** - root container. Owns pointer tracking, tilt, orientation, and foil rendering.
- **HoloCardImage** - marker child. Switches to image mode and supplies `src` and `alt`.

## Image mode

Pass a `HoloCardImage` child or set `variant="image"` to render artwork under the foil. Presets combine with both card and image modes.

## Presets

| Preset | Foil shape |
| :-- | :-- |
| `bursts` | Radial bursts from the pointer position. Default. |
| `cosmos` | Layered rings and fine dust. |

## Accessibility

- Pass a meaningful `alt` to `HoloCardImage` or the `alt` prop on `HoloCard`.
- Tilt follows the pointer on desktop and the device orientation on touch devices.
- Motion respects `prefers-reduced-motion` - tilt, springs, and orientation are disabled.
- The card is focusable only when a `backImage` is provided for flip interaction.

## Best Practices

- **Use artwork that reads at a glance.** In image mode the foil adds motion; the image carries identity.
- **Provide a `logo` for card mode.** Without one, only the chip is visible in the bottom-right region.
- **Keep `intensity` between 0.6 and 0.9.** High values overwhelm text layered on top.
- **Pick `bursts` for bright palettes, `cosmos` for dark palettes.** Bursts read best on colorful art; cosmos reads best on deep backgrounds.
