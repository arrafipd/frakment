Credit Card renders a card display from raw data. It detects the brand from the number prefix, groups the digits, and formats the expiry - with a `masked` mode for saved-card lists and a `glass` variant for translucent surfaces.

## Usage

```tsx title="credit-card.tsx"
import {
  CreditCard,
  CreditCardBrand,
  CreditCardExpiry,
  CreditCardFooter,
  CreditCardHeader,
  CreditCardHolder,
  CreditCardIssuer,
  CreditCardNumber,
} from "@/components/ui/credit-card";
```

```tsx title="credit-card.tsx"
<CreditCard>
  <CreditCardHeader>
    <CreditCardIssuer />
    <CreditCardBrand brand="visa" />
  </CreditCardHeader>
  <CreditCardNumber value="4242424242424242" />
  <CreditCardFooter>
    <CreditCardHolder value="John Doe" />
    <CreditCardExpiry value="1228" />
  </CreditCardFooter>
</CreditCard>
```

Pass raw data to sub-components. `CreditCardNumber` handles brand detection and grouping; `CreditCardExpiry` normalizes the expiry.
## Anatomy

```tsx title="credit-card.tsx"
<CreditCard>
  <CreditCardHeader>
    <CreditCardIssuer />
    <CreditCardBrand brand="visa" />
  </CreditCardHeader>
  <CreditCardNumber value="4242424242424242" />
  <CreditCardFooter>
    <CreditCardHolder value="John Doe" />
    <CreditCardExpiry value="1228" />
  </CreditCardFooter>
</CreditCard>
```

- **CreditCard** - root container. Accepts `variant`.
- **CreditCardHeader** - top row, flex with space-between.
- **CreditCardIssuer** - left slot, defaults to the Frakment mark. Accepts children for a custom logo.
- **CreditCardBrand** - right slot. Pass `brand` for a network logo or children for a custom mark.
- **CreditCardNumber** - number, accepts `value`, optional `brand`, `masked`.
- **CreditCardFooter** - bottom row.
- **CreditCardHolder** - cardholder name, accepts `value` and optional `label`.
- **CreditCardExpiry** - expiry, accepts `value` and optional `label`.

## Animation

`CreditCardNumber` accepts an `animation` prop. The transition applies per character when the number or mask state changes, using `stagger` as the per-character delay.

```tsx
<CreditCardNumber
  value="4242424242424242"
  masked={masked}
  animation="spring(300, 25) delay(50ms)"
/>
```

| Form | Example |
| :-- | :-- |
| Named easing | `"easeInOut"`, `"easeOutExpo"`, `"easeSmoothOut"` |
| Named easing + duration | `"easeInOut 300ms"`, `"easeOutExpo 0.5"` |
| Custom curve | `"cubic-bezier(0.4, 0, 0.2, 1) 300ms"` |
| Spring | `"spring(300, 25)"` |

Any form supports `delay(...)` and `repeat(n | infinite)`. Pass `animation={false}` to render plain text without motion markup.

## Accessibility

- The number uses `tabular-nums` so columns do not shift when toggling masked mode.
- Brand icons carry an `aria-label` with the network name.
- The root container is not focusable. Wrap in an anchor or button if the card opens a detail view.
- In `masked` mode the visible text is masked. Do not expose the full number in adjacent layout if it is meant to be hidden.

## Best Practices

- **Use `masked` for saved-card lists**, never for the primary display of the card being confirmed.
- **Pass raw numbers** - do not pre-format. The component handles grouping and expiry normalization.
- **Reserve `glass` for layered surfaces**. On plain backgrounds the blur has nothing to sample and reads flat.
- **Keep labels short**. Card holder and Expires fit two words. Longer labels wrap and break the footer layout.
