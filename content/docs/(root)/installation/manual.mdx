Use this guide if you prefer to copy files yourself instead of using the CLI. It works in any React 19 + Tailwind v4 project.

## Prerequisites

- **React** 19
- **Tailwind CSS** v4
- **TypeScript**
- **Node.js** 18 or newer

Components target React 19 and Tailwind v4. For React 18, some components need `forwardRef` adjustments. For Tailwind v3, port the tokens from [Theming](/docs/theming) manually.

## Setup

<Steps>

<Step>Install dependencies</Step>

```bash
npm install class-variance-authority clsx tailwind-merge lucide-react radix-ui
```

<Step>Configure the import alias</Step>

In `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": { "@/*": ["./*"] }
  }
}
```

<Step>Create lib/utils.ts</Step>

```ts title="lib/utils.ts"
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

<Step>Add theme.css</Step>

Copy [`theme.css`](https://github.com/hanshapd/frakment/blob/main/styles/theme.css) into the same folder as your `globals.css`, then import it **after** `@import "tailwindcss";`:

```css title="app/globals.css"
@import "tailwindcss";
@import "./theme.css";
```

`theme.css` contains the design tokens (`:root` + `.dark`), `@custom-variant dark` (for `dark:` utilities), `@theme inline` (Tailwind mapping), and 9 `@utility` helpers. Dark mode works as soon as `<html>` gets the `.dark` class — no extra setup. See [Theming](/docs/theming) for tokens and dark-mode wiring.

<Alert variant="warning" className="mt-6">
  <AlertTitle>Import order matters</AlertTitle>
  <AlertDescription>
    `@import "./theme.css";` must come **after** `@import "tailwindcss";` and
    **before** any other CSS. Imports placed below other rules are silently
    ignored by browsers — components will render unstyled.
  </AlertDescription>
</Alert>

<Step>Copy a component</Step>

Every component is a single `.tsx` file under `registry/`. Browse the [catalog](/docs/ai-elements/bubble) and copy the source into `components/ui/`, or run:

```bash
npx frakment@latest add bubble
```

</Steps>

## Project structure

After completing the setup steps, your project will have:

<FileTree>
  <FileTreeFolder name="my-app" defaultOpen>
    <FileTreeFile name="components.json" />
    <FileTreeFile name="package.json" />
    <FileTreeFile name="tsconfig.json" />
    <FileTreeFile name="globals.css" />
    <FileTreeFolder name="components">
      <FileTreeFolder name="ui" defaultOpen>
        <FileTreeFile name="bubble.tsx" />
        <FileTreeFile name="button.tsx" />
      </FileTreeFolder>
    </FileTreeFolder>
    <FileTreeFolder name="lib" defaultOpen>
      <FileTreeFile name="utils.ts" />
    </FileTreeFolder>
  </FileTreeFolder>
</FileTree>

## Verify

After installing your first component, confirm the setup:

```bash
ls components/ui/bubble.tsx
```

Then import and render it in your app. If it renders without errors, you're ready.

## Troubleshooting

<Accordion type="single" collapsible>

<AccordionItem value="missing-utils">
<AccordionTrigger>Cannot find module lib/utils</AccordionTrigger>
<AccordionContent>

Make sure `lib/utils.ts` exists and your `tsconfig.json` defines the `@/*` alias.

</AccordionContent>
</AccordionItem>

<AccordionItem value="styles">
<AccordionTrigger>Styles do not apply</AccordionTrigger>
<AccordionContent>

Make sure your `globals.css` includes the theme tokens from [Theming](/docs/theming).

</AccordionContent>
</AccordionItem>

</Accordion>
