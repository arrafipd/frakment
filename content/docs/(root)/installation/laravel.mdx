---
title: Laravel
description: Install Frakment in a Laravel project.
---

Frakment works with Laravel 12 + Inertia + React + Tailwind v4 via Vite.

## Create project

```bash
laravel new my-app --react
cd my-app
```

## Install Tailwind v4

```bash
npm install tailwindcss@latest @tailwindcss/vite
```

Update `vite.config.ts`:

```ts title="vite.config.ts"
import tailwindcss from "@tailwindcss/vite";
import laravel from "laravel-vite-plugin";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    laravel({ input: ["resources/css/app.css", "resources/js/app.tsx"], refresh: true }),
    react(),
    tailwindcss(),
  ],
});
```

## Run init

```bash
npx frakment init
```

Point to `resources/css/app.css`.

## Add a component

```bash
npx frakment add button
```

Components land in `resources/js/components/ui/`.
