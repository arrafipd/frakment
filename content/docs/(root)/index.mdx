**Frakment** is a component registry for React interfaces. Every component is standalone, depends only on a small set of well-known libraries, and ships as open source you can read, copy, and modify.

<Callout type="info" title="AI and motion, built in">

Components designed for agent surfaces ship with AI support and motion already resolved per file. Baseline primitives stay motion-ready without extra setup.

</Callout>

## Principles

### Zero hidden dependencies

Every component depends only on `radix-ui`, `class-variance-authority`, and `@phosphor-icons/react`. There is no hidden dependency chain you need to install or keep in sync.

### Composable by design

All components follow the same shape: a root (`Bubble`), a content slot (`BubbleContent`), and variants via `cva`. This is predictable for you, and for LLMs reading the code.

### Distribution via CLI and registry

A flat-file registry (`public/r/*.json`) and a CLI (`npx frakment add`) make it easy to distribute components across projects. Each component is a JSON manifest with its source, npm dependencies, and registry dependencies.

### Considered defaults

The defaults are opinionated so you don't have to build the basics yourself. Components are designed for real product use — chat surfaces, agent traces, forms, and code output alike.

### AI and motion, built in

Components that need agent surfaces or animated states ship with AI support and motion resolved per file. The registry also publishes \ llms.txt, `an agent catalog endpoint, and an MCP server so AI tools can read and extend the source directly.`
