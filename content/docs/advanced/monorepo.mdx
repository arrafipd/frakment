Frakment works in a monorepo where one package holds the components and multiple apps import from it. This guide uses Turborepo + pnpm workspaces as the reference setup — the same pattern works with npm/yarn workspaces and Nx.

## Prerequisites

- A working monorepo (Turborepo, Nx, or plain workspaces)
- **TypeScript** shared across packages
- **Tailwind CSS** v4 in the UI package

## Set up the UI package

From `packages/ui`, run init:

```bash
cd packages/ui
npx frakment@latest init
```

Point to `src/styles.css` when prompted. Components land in `src/components/ui/`.

Add a component:

```bash
npx frakment@latest add button bubble
```

## Share the package

In `packages/ui/package.json`, expose the components and styles:

```json title="packages/ui/package.json"
{
  "name": "@myorg/ui",
  "version": "0.0.0",
  "private": true,
  "exports": {
    "./*": "./src/components/ui/*.tsx",
    "./styles.css": "./src/styles.css"
  },
  "peerDependencies": {
    "react": "^19.0.0",
    "react-dom": "^19.0.0",
    "tailwindcss": "^4.0.0"
  }
}
```

## Import from apps

In `apps/web/package.json`:

```json
{
  "dependencies": {
    "@myorg/ui": "workspace:*"
  }
}
```

In `apps/web/app/layout.tsx`:

```tsx title="apps/web/app/layout.tsx"
import "@myorg/ui/styles.css";
```

In any page:

```tsx
import { Button } from "@myorg/ui/button";

export default function Page() {
  return <Button>Click me</Button>;
}
```

## Tailwind content scanning

Tailwind v4 scans the source of every dependency automatically. If styles do not apply, add the UI package to `@source` in the app CSS:

```css title="apps/web/app/globals.css"
@import "tailwindcss";
@import "@myorg/ui/styles.css";
@source "../../../packages/ui/src";
```

## Best practices

- **One `components.json` per package.** Do not init from the monorepo root.
- **Shared `tsconfig.json` base.** Every app must resolve `@myorg/ui` from `paths` or workspace protocol.
- **Peer dependencies for UI.** Add `react`, `react-dom`, and `tailwindcss` as peers — not dependencies — in `packages/ui`.
- **One Tailwind config per app.** Each app can override tokens via its own `globals.css`.

## Common errors

<Accordion type="single" collapsible>

<AccordionItem value="no-styles">
<AccordionTrigger>Components render without styles</AccordionTrigger>
<AccordionContent>

Tailwind is not scanning `packages/ui/src`. Add `@source "../path/to/packages/ui/src"` in the app CSS after the Tailwind import.

</AccordionContent>
</AccordionItem>

<AccordionItem value="module-not-found">
<AccordionTrigger>Cannot resolve @myorg/ui/*</AccordionTrigger>
<AccordionContent>

Check the `exports` field in `packages/ui/package.json`. Each subpath must exist. Run `pnpm install` after changing exports.

</AccordionContent>
</AccordionItem>

<AccordionItem value="react-mismatch">
<AccordionTrigger>Invalid hook call</AccordionTrigger>
<AccordionContent>

Two React copies are loaded. Add `react` and `react-dom` to `peerDependencies` in `packages/ui`, and enable `resolve.dedupe` in the app Vite config if needed.

</AccordionContent>
</AccordionItem>

</Accordion>
