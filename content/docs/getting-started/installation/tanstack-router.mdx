Frakment works in any TanStack Router project with React 19 and Tailwind v4. This guide covers both a new project via the CLI and an existing app.

## Prerequisites

- **TanStack Router** 1.x
- **React** 19
- **Vite** 5+
- **TypeScript**
- **Tailwind CSS** v4

Components target React 19 and Tailwind v4. For React 18, some components need `forwardRef` adjustments. For Tailwind v3, port the tokens from [Theming](/docs/guides/theming) manually.

## Use the CLI

Scaffold a new TanStack Router app with Frakment installed.

<Steps>

<Step>Create project</Step>

```bash
npx create-tsrouter-app@latest app --template file-router
cd app
```

<Step>Install Tailwind v4</Step>

```bash
npm install tailwindcss@latest @tailwindcss/vite
```

Register the Vite plugin:

```ts title="vite.config.ts"
import { tanstackRouter } from "@tanstack/router-plugin/vite";
import tailwindcss from "@tailwindcss/vite";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [tanstackRouter(), react(), tailwindcss()],
});
```

<Step>Add components</Step>

```bash
npx frakment@latest init
npx frakment@latest add bubble
```

<Step>Use it</Step>

```tsx title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router";
import { Bubble, BubbleContent } from "@/components/ui/bubble";

export const Route = createFileRoute("/")({
  component: Index,
});

function Index() {
  return (
    <Bubble>
      <BubbleContent>Hello, Frakment.</BubbleContent>
    </Bubble>
  );
}
```

</Steps>

## Existing Project

Add Frakment to a TanStack Router app you already created.

<Steps>

<Step>Install Tailwind v4</Step>

```bash
npm install tailwindcss@latest @tailwindcss/vite
```

Register the Vite plugin:

```ts title="vite.config.ts"
import { tanstackRouter } from "@tanstack/router-plugin/vite";
import tailwindcss from "@tailwindcss/vite";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [tanstackRouter(), react(), tailwindcss()],
});
```

<Step>Run frakment init</Step>

```bash
npx frakment@latest init
```

Point to `src/styles.css` when prompted. The CLI injects the theme block.

<Step>Configure the import alias</Step>

In `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

<Step>Add a component</Step>

```bash
npx frakment@latest add bubble
```

</Steps>

## Verify

```bash
ls src/components/ui/bubble.tsx
```

Then render it in a route. If it renders without errors, you are ready.

## Troubleshooting

<Accordion type="single" collapsible>

<AccordionItem value="route-plugin">
<AccordionTrigger>Route file not picked up</AccordionTrigger>
<AccordionContent>

Make sure `tanstackRouter()` is the first plugin in `vite.config.ts`. The router plugin scans `src/routes/` at build time.

</AccordionContent>
</AccordionItem>

<AccordionItem value="alias">
<AccordionTrigger>Cannot resolve @/components</AccordionTrigger>
<AccordionContent>

TanStack apps put source in `src/`. Set `"@/*": ["./src/*"]` in `tsconfig.json` and `"components": "@/components"` in `components.json`.

</AccordionContent>
</AccordionItem>

</Accordion>
