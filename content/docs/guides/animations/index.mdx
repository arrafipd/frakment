Every animated Frakment component ships with its motion already wired. State transitions run on Motion, the CLI installs the `motion` package the first time you add a component that needs it, and every animated component pulls in the helpers it depends on. You never install anything by hand.

## Installation

Motion ships with Frakment through the CLI. Two commands are enough:

```bash
npx frakment@latest init
npx frakment@latest add button
```

`init` runs once per project. It creates `lib/animation.ts` with the shared helper tokens, installs `motion`, and wires up the base dependencies (React 19, Tailwind v4). `add` runs once per component - it copies the component source into your project and installs whatever npm package that component animates with. No global config, no extra build step. Motion is available the moment the first animated component lands in your tree.

## Default motion

These components animate out of the box - no prop required. A custom `animation` prop is also available on five Motion state-transition components. See [Custom animation prop](#custom-animation-prop).

## Custom animation prop

Five Motion state-transition components accept an `animation` prop. Pass a string; the parser (`parseAnimation` in `lib/animation.ts`) converts it into a Motion `transition`. No need to import `motion` yourself.

| Component | Prop location |
| :-- | :-- |
| Accordion | `<Accordion animation>` (inherited) + `<AccordionContent animation>` (per-item) |
| Collapsible | `<Collapsible animation>` + `<CollapsibleContent animation>` |
| Trace | `<TraceCollapsible animation>` + `<TraceCollapsibleContent animation>` |
| Credit Card | `<CreditCardNumber animation>` (per character; uses `stagger` as delay) |
| Text Morph | `<TextMorph animation>` (overrides `transition` prop when set) |

```tsx
<Accordion animation="spring(300, 25)" collapsible type="single">
  <AccordionItem value="a">
    <AccordionTrigger>Shipping options</AccordionTrigger>
    <AccordionContent animation="easeOutExpo 400ms">...</AccordionContent>
  </AccordionItem>
</Accordion>
```

### Syntax

One required primary token, then any number of modifiers. Tokens separated by spaces; parentheses and brackets preserved, so `keyframes([0, 1, 0])` is one token.

Primary token (exactly one):

| Form | Example | Maps to |
| :-- | :-- | :-- |
| Named easing | `easeInOut`, `easeOutExpo`, `easeSmoothOut`, `linear`, `backOut`, `anticipate` | `{ type: "tween", ease }` |
| Custom Bezier | `cubic-bezier(0.4, 0, 0.2, 1)` | `{ type: "tween", ease: [x1, y1, x2, y2] }` |
| Spring | `spring(stiffness, damping)`, e.g. `spring(300, 25)` | `{ type: "spring", stiffness, damping }` |

Modifiers (any order, repeatable):

| Form | Example | Notes |
| :-- | :-- | :-- |
| Duration | `300ms`, `0.3s`, `0.3` | Tween only. Ignored on `spring`. |
| Delay | `delay(100ms)` | Any transition type. |
| Repeat | `repeat(3)`, `repeat(infinite)` | Any transition type. |

```text
spring(300, 25) delay(100ms) repeat(3)
easeOutExpo 400ms
cubic-bezier(0.4, 0, 0.2, 1) 300ms delay(50ms)
```

### Disable per instance

```tsx
<Accordion animation={false} collapsible type="single">...</Accordion>
```

`false` disables the animation for that instance. Omitting the prop keeps the internal default. `false` is not "use default" — it is "no animation".

### Reduced motion

When the user has `prefers-reduced-motion: reduce`, all five components force `{ duration: 0 }` regardless of the prop value.

### Invalid input

If the string cannot be parsed, `parseAnimation` logs `[motion-dsl] <reason>` to the console and returns `null`. The component then falls back to its internal default. No crash, no broken UI.

```tsx
<Accordion animation="spring(abc, def)">   // warns, falls back to default
<Accordion animation="wobbleOut 300ms">     // warns, falls back to default
```

### Not yet wired

Two tokens are parsed but have no visible effect on the five components:

- `inertia(power, timeConstant)` — physics deceleration from a starting velocity. State transitions start at rest, so there is no velocity to decelerate from.
- `keyframes([values], [times]?)` — parsed into `{ type: "tween" }` with metadata attached, but no component consumes the keyframe values. Height cannot overshoot (`auto` is not a number), so a keyframe curve on height is a no-op.

For bounce-like effects, use `spring(...)` or a `cubic-bezier(...)` with overshoot handles such as `backOut`.

### Per-component behavior

- **Accordion** — animates `height` and `opacity` together. Default: `height` uses `durationSlow` + `easeSmoothOut`, `opacity` uses `0.2s`. Setting `animation` replaces both with a single shared transition.
- **Collapsible** — animates `height`. Default: `durationSlow` + `easeSmoothOut`.
- **Trace** — animates `height` and `opacity`. Default: `height` uses `springSoft`, `opacity` uses `0.3s` + `easeOutExpo`. Ignored when `animateHeight={false}`.
- **Credit Card** — animates `scale`, `opacity`, and `filter: blur` per character. `stagger` sets the delay between characters. Default transition: `durationSlow` + `easeInOutQuad`.
- **Text Morph** — passes the parsed transition to its internal `motion.span` (for `flip`, `slide`, `fade`, `blur`, `scale` variants). Priority: `animation` string > `transition` prop > internal default (`{ duration: 0.3 }`).

### Limitations

- **No per-property transitions.** One transition object applies to every animated property. To control `height` and `opacity` separately, leave `animation` unset and edit the source.
- **`springSoft` cannot be referenced by name.** The token is an object, not a string. Use `spring(200, 30)`.
- **Duration is ignored on spring and inertia.** Physics transitions derive duration from their parameters.
- **`steps(...)` is not a stepping easing.** Parser accepts it but maps to `ease: "linear"`.

## Durations

Three duration tokens paired with any easing above.

| Name | Value |
| :-- | :-- |
| `fast` | 0.2s |
| `normal` | 0.3s |
| `slow` | 0.45s |

Exported as `durationFast`, `durationNormal`, `durationSlow` from `@/lib/animation`.

## Springs

Physics-based transitions that settle naturally without a fixed duration.

| Name | Config |
| :-- | :-- |
| `springSoft` | stiffness 200, damping 30 |

Reach for `springSoft` when an element should feel physical rather than timed. Expand and collapse in Accordion, Collapsible, and Trace all use it.

## Motion vs CSS

Every animation in Frakment picks the smallest tool that fits. Six components animate with Motion (JS-driven, per-frame control). Seven animate with pure CSS keyframes on Radix `data-state` attributes.

**Motion** (`motion/react`) - per-frame control, springs, per-character orchestration:

- Accordion, Collapsible, Trace - height animation with spring settle
- Message Animated, Credit Card (Masked) - per-character stagger
- Text Flip - layout transitions per variant

**CSS** (`tw-animate-css` + Radix `data-state`) - zero JS at runtime, runs on the compositor thread:

- Dialog, Sheet, Dropdown Menu, Select, Tooltip, Hover Card, Tabs

Neither system requires extra setup. `npx frakment@latest init` installs Motion; Radix and `tw-animate-css` arrive with the components that need them. The split exists so that simple enter/exit transitions stay off the JS main thread, and only the animations that genuinely need per-frame calculations ship a Motion bundle.

## Two systems, one install

Frakment uses two animation engines behind the scenes. You do not choose between them - the CLI installs whatever a component declares.

- **Motion** - every state transition (accordion height, collapsible expand, trace collapse, text flip, shimmer, attachment loading). Backed by the `motion` npm package.
- **NumberFlow** - numeric roll and count variants in Text Flip. Backed by `@number-flow/react`.

A third-party layer fills the rest: Tailwind's `animate-spin` for loaders, and `tw-animate-css` for dropdown and dialog entrances. Those ship inside Tailwind and `tw-animate-css`, not Frakment, and require nothing extra from you.

## Shared helpers

`lib/animation.ts` is created by `npx frakment init`. Import from it when you build your own animated components so timing matches the rest of the library.

```ts
import { springSoft, easeInOutQuad, easeOutExpo, easeSmoothOut, durationSlow } from "@/lib/animation";
```

- `springSoft` - `{ stiffness: 200, damping: 30 }`. Expand and collapse that should settle without bounce.
- `easeInOutQuad` - `[0.45, 0, 0.55, 1]`. Default for per-character morph (Credit Card mask).
- `easeOutExpo` - `[0.16, 1, 0.3, 1]`. Entrances that decelerate.
- `easeSmoothOut` - `[0.32, 0.72, 0, 1]`. Default for Frakment height transitions.
- `durationFast` / `durationNormal` / `durationSlow` - `0.2` / `0.3` / `0.45` seconds.
- `delayTight` - `0.02` seconds. Per-character stagger delay.

## Usage

Every Frakment animated component imports Motion and its tokens from `@/lib/animation`. Follow the same pattern when you build your own.

### Enter

```tsx
"use client";

import { motion } from "motion/react";
import { durationNormal, easeOutExpo } from "@/lib/animation";

export function FadeIn({ children }: { children: React.ReactNode }) {
  return (
    <motion.div
      animate={{ opacity: 1, y: 0 }}
      initial={{ opacity: 0, y: 8 }}
      transition={{ duration: durationNormal, ease: easeOutExpo }}
    >
      {children}
    </motion.div>
  );
}
```

### Expand height

```tsx
"use client";

import { motion } from "motion/react";
import { durationSlow, easeSmoothOut } from "@/lib/animation";

export function CollapsibleBody({ open, children }: { open: boolean; children: React.ReactNode }) {
  return (
    <motion.div
      animate={{ height: open ? "auto" : 0 }}
      initial={false}
      style={{ overflow: "hidden" }}
      transition={{ duration: durationSlow, ease: easeSmoothOut }}
    >
      {children}
    </motion.div>
  );
}
```

### Spring settle

```tsx
"use client";

import { motion } from "motion/react";
import { springSoft } from "@/lib/animation";

export function SpringPanel({ open, children }: { open: boolean; children: React.ReactNode }) {
  return (
    <motion.div
      animate={{ height: open ? "auto" : 0 }}
      initial={false}
      style={{ overflow: "hidden" }}
      transition={springSoft}
    >
      {children}
    </motion.div>
  );
}
```

### Reduced motion

Always respect the user's system preference. Use `useReducedMotion` from Motion:

```tsx
"use client";

import { motion, useReducedMotion } from "motion/react";
import { durationSlow, easeSmoothOut } from "@/lib/animation";

export function Safe({ open }: { open: boolean }) {
  const reduce = useReducedMotion();
  return (
    <motion.div
      animate={{ opacity: open ? 1 : 0 }}
      transition={reduce ? { duration: 0 } : { duration: durationSlow, ease: easeSmoothOut }}
    />
  );
}
```

## Shimmer

`Shimmer` is a Motion component that animates a text gradient. Trace and Attachment use it internally when their state is `running`, `processing`, or `uploading`, but it works anywhere.

```tsx
import { Shimmer } from "@/components/ui/shimmer";

<Shimmer>Loading registry...</Shimmer>
```

Run `npx frakment add shimmer` to install it on its own, or let another component pull it in.

## Customising

Every animated component accepts a `className` and works with Motion's `transition` overrides where it exposes them. `CreditCardNumber` accepts `masked`, `animation`, `duration`, and `stagger` directly. Trace and Collapsible expose `animateHeight` to opt out of the built-in height animation when you provide your own. See each component page for props.
