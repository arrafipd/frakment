The `shimmer` utility animates a gradient over text to signal a loading or streaming state. It is applied as a class on any text element.

## Usage

```tsx
<p className="shimmer">Generating response&hellip;</p>
```

`shimmer-once` runs the animation once.

</ComponentPreview>

## Disable

`shimmer-none` disables the animation. Combine with a breakpoint for responsive control.

<ComponentPreview name="shimmer-none" title="shimmer-none.tsx">
  <ShimmerNone />
</ComponentPreview>

## Accessibility

Shimmer is decorative. Pair it with a visible text label so the loading state is conveyed to screen readers.
